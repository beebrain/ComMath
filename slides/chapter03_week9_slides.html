Concept 1.1

ลำดับในมุมมองของฟังก์ชัน (Sequence as a Function)

DEF นิยามเชิงคณิตศาสตร์
ลำดับ (Sequence) คือ ฟังก์ชันที่โดเมนถูกจำกัดให้เป็นเซตของจำนวนเต็มบวก $\mathbb{Z}^+ = \{1, 2, 3, \dots\}$: $$\mathbf{a: \mathbb{Z}^+ \to \mathbb{R}}$$ นิยมเขียนสัญลักษณ์ผลลัพธ์ $a(n)$ ด้วย พจน์ที่ $n$ หรือ $a_n$
ANALOGY มโนภาพในชีวิตจริง: สมุดบัญชีเงินฝากรายเดือน
เปรียบเสมือน สมุดบัญชีเงินฝากธนาคาร ที่บันทึกยอดเงินตามงวดเวลา:
• โดเมน ($\mathbb{Z}^+$): คืองวดเดือนที่ $1, 2, 3, \dots$ (ลำดับเวลาที่แน่นอน)
• เรนจ์ ($\mathbb{R}$): คือยอดเงินในบัญชีจริง $a_1, a_2, a_3, \dots$ (เช่น 1,000, 1,500, 2,000 บาท)
ช่วยให้เราสามารถทำนายยอดเงินในอนาคตได้ล่วงหน้าโดยใช้ฟังก์ชันทางคณิตศาสตร์
การจับคู่แบบ 1 ต่อ 1 จากงวดเวลา $n$ ไปสู่ยอดเงิน $a_n$

Concept 1.2

ลำดับเลขคณิต (Arithmetic Sequence)

ANALOGY มโนภาพในชีวิตจริง: การออมเงินแบบฝากเพิ่มรายเดือนคงที่
เปิดบัญชีมีเงินตั้งต้น 1,000 บาท ($a_1 = 1,000$) และฝากเงินเพิ่มเดือนละ 500 บาทเท่ากันทุกเดือน ($d = 500$):
• สิ้นเดือน 1: $1,000$ บาท  • สิ้นเดือน 2: $1,000 + 500 = 1,500$ บาท  • สิ้นเดือน 3: $1,500 + 500 = 2,000$ บาท
• สิ้นปี (เดือนที่ 12): $a_{12} = 1,000 + 11(500) = \mathbf{6,500 \text{ บาท}}$ (เพิ่มด้วยอัตราคงที่)
FORMULA การคลี่รูปเพื่อหาสูตรพจน์ทั่วไป
• พจน์ที่ 1: $a_1$
• พจน์ที่ 2: $a_2 = a_1 + d$
• พจน์ที่ 3: $a_3 = a_2 + d = a_1 + 2d$
• พจน์ที่ 4: $a_4 = a_3 + d = a_1 + 3d$
$$\mathbf{\implies a_n = a_1 + (n - 1)d}$$ โดย $d = a_{n+1} - a_n$ คือ ผลต่างร่วม (Common Difference)
PROPERTIES พฤติกรรมและข้อสังเกต
1. ถ้า $d > 0$ เงินเพิ่มขึ้นเรื่อยๆ (Strictly Increasing)
2. ถ้า $d < 0$ ถอนเงินคงที่ ยอดเงินลดลงเรื่อยๆ (Strictly Decreasing)
3. ถ้า $d = 0$ ไม่เคลื่อนไหว ยอดเงินคงที่ตลอด ($a_n = a_1$)
มโนภาพ: บันไดเงินออมรายเดือน เพิ่มขึ้นงวดละ $d = +500$ บาทคงที่

Example 1.3

ตัวอย่างที่ 1 — การหาพจน์ทั่วไปและพจน์ที่กำหนด ($a_{50}$)

PROBLEM โจทย์ตัวอย่าง
กำหนดลำดับเลขคณิต $3, 7, 11, 15, \dots$ จงหาผลต่างร่วม $d$, พจน์ทั่วไป $a_n$, และพจน์ที่ 50 ($a_{50}$)
ขั้นที่ 1
หาพจน์แรกและผลต่างร่วม: พจน์แรก $a_1 = 3$, ผลต่างร่วม $d = a_2 - a_1 = 7 - 3 = \mathbf{4}$
ขั้นที่ 2
ตั้งสูตรพจน์ทั่วไป: $a_n = 3 + (n-1)(4) = 3 + 4n - 4 = \mathbf{4n - 1}$
ขั้นที่ 3
คำนวณพจน์ที่ 50: $a_{50} = 4(50) - 1 = \mathbf{199}$
หรือใช้สูตร $a_{50} = 3 + (49 \times 4) = 3 + 196 = \mathbf{199}$
📈 กราฟลำดับ $a_n = 4n - 1$ (ความชัน $d = 4$)
จุดข้อมูล $a_1=3, a_2=7, \dots a_5=19$ และจุดปลาย $a_{50}=199$

Example 1.4

ตัวอย่างที่ 2 — การหาจำนวนพจน์ทั้งหมดของลำดับ (Find $n$)

PROBLEM โจทย์ตัวอย่าง
กำหนดลำดับเลขคณิต $7, 11, 15, 19, \dots, 83$ จงหาว่าลำดับนี้มีทั้งหมดกี่พจน์?
ขั้นที่ 1
ระบุค่าคงที่ที่ทราบ: พจน์แรก $a_1 = 7$, ผลต่างร่วม $d = 4$, พจน์สุดท้าย $a_n = 83$
ขั้นที่ 2
แทนค่าลงในสมการพจน์ทั่วไป:
$$83 = a_1 + (n - 1)d \implies 83 = 7 + (n - 1)(4)$$
ขั้นที่ 3
แก้สมการเชิงเส้นหาค่า $n$:
$76 = 4(n - 1) \implies n - 1 = 19 \implies \mathbf{n = 20}$
สรุป: ลำดับนี้มีสมาชิกทั้งหมด 20 พจน์
📊 กราฟหาจำนวนพจน์ $n = 20$ (สู่ค่า $83$)
พจน์ที่ 1 ($a_1=7$) ก้าวทีละ $+4$ รวม 19 ช่วงสู่พจน์ที่ 20 ($a_{20}=83$)

Example 1.5

ตัวอย่างที่ 3 — การแก้ระบบสมการหา $a_1$ และ $d$ เมื่อรู้สองพจน์ใดๆ

PROBLEM โจทย์ตัวอย่าง
กำหนดลำดับเลขคณิตที่มีพจน์ที่ 3 คือ $a_3 = 13$ และพจน์ที่ 7 คือ $a_7 = 29$ จงหา $a_1$, $d$, และ $a_n$
ขั้นที่ 1
ตั้งระบบสมการ: (1) $a_1 + 2d = 13$ และ (2) $a_1 + 6d = 29$
ขั้นที่ 2
กำจัดตัวแปรโดยนำ (2) ลบด้วย (1):
$(a_1 + 6d) - (a_1 + 2d) = 29 - 13 \implies 4d = 16 \implies \mathbf{d = 4}$
ขั้นที่ 3
แทนค่า $d = 4$ ในสมการ (1) หา $a_1$:
$a_1 + 2(4) = 13 \implies \mathbf{a_1 = 5} \implies \mathbf{a_n = 4n + 1}$
📐 ระนาบพิกัด $(n, a_n)$ และความชัน $d = 4$
จุด $(3, 13)$ และ $(7, 29) \implies d = (29-13)/(7-3) = 4$

Concept 1.6

ลำดับเรขาคณิต (Geometric Sequence)

ANALOGY มโนภาพในชีวิตจริง: การเติบโตของเงินลงทุนแบบทบเท่าตัว (Compound Doubling)
ฝากเงินต้น 10,000 บาท ($a_1 = 10,000$) ในกองทุนที่มูลค่าเพิ่มขึ้นเป็น 2 เท่า ($r = 2$) ทุกปี:
• สิ้นปี 1: $10,000$ บาท  • สิ้นปี 2: $10,000 \times 2 = 20,000$ บาท  • สิ้นปี 3: $20,000 \times 2 = 40,000$ บาท
• สิ้นปี 5: $a_5 = 10,000 \times 2^4 = \mathbf{160,000 \text{ บาท}}$ (เพิ่มขึ้นด้วยการคูณทบเท่าตัวต่องวด)
FORMULA การคลี่รูปเพื่อหาสูตรพจน์ทั่วไป
• พจน์ที่ 1: $a_1$
• พจน์ที่ 2: $a_2 = a_1 \cdot r$
• พจน์ที่ 3: $a_3 = a_2 \cdot r = a_1 \cdot r^2$
• พจน์ที่ 4: $a_4 = a_3 \cdot r = a_1 \cdot r^3$
$$\mathbf{\implies a_n = a_1 \cdot r^{n-1}}$$ โดย $r = \frac{a_{n+1}}{a_n}$ คือ อัตราส่วนร่วม (Common Ratio)
INTERPRET การประยุกต์ในชีวิตประจำวัน
• ดอกเบี้ยทบต้น $10\%$ ต่อปี: $r = 1 + 0.10 = 1.10$
• ประชากรแบคทีเรีย: ทวีคูณเท่าตัวทุกชั่วโมง ($r = 2$)
มโนภาพ: เงินลงทุนทบเท่าตัว ($r = 2$) พุ่งทะยานแบบ Exponential

PROBLEM โจทย์ตัวอย่าง
กำหนดลำดับเรขาคณิต $2, 6, 18, 54, \dots$ จงหาอัตราส่วนร่วม $r$, พจน์ทั่วไป $a_n$, และพจน์ที่ 8 ($a_8$)

Concept 2.1

นิยามอนุกรมและสัญกรณ์ซิกมา (Series & Sigma $\sum$)

ANALOGY มโนภาพในชีวิตจริง: ยอดเงินรวมสะสมในสมุดบัญชี (Cumulative Bank Balance)
• ลำดับ ($a_i$): คือยอดเงินที่ฝากเพิ่มในแต่ละเดือน เช่น เดือนที่ 1 ฝาก 1,000, เดือนที่ 2 ฝาก 1,500, เดือนที่ 3 ฝาก 2,000
• อนุกรม ($S_n$): คือ ยอดเงินรวมสะสมทั้งหมดในบัญชี ตั้งแต่เดือนแรกถึงเดือนที่ $n$: $$\mathbf{S_n = \sum_{i=1}^n a_i = a_1 + a_2 + a_3 + \dots + a_n}$$
RULES สมบัติของสัญกรณ์ซิกมา
1. $\sum_{i=1}^n c = n \cdot c$ (ฝากเงินคงที่ $c$ บาททุกเดือน รวม $n$ เดือน ได้ $n \cdot c$ บาท)
2. $\sum_{i=1}^n c \cdot a_i = c \sum_{i=1}^n a_i$ (ดึงตัวคูณร่วมออกนอกซิกมาได้)
3. $\sum_{i=1}^n (a_i \pm b_i) = \sum_{i=1}^n a_i \pm \sum_{i=1}^n b_i$ (แยกบวก-ลบระหว่างบัญชีได้)
MEANING ความสำคัญในชีวิตจริง
หาก $a_i$ คือยอดเงินที่ออมในแต่ละงวด $i$ ผลรวม $S_n = \sum a_i$ คือ ความมั่งคั่งสะสมรวมทั้งหมด (Total Wealth)
โครงสร้างของสัญกรณ์ผลรวมซิกมา $\sum$

Concept 2.2

อนุกรมเลขคณิตและที่มาของสูตร (Gauss's Pairing Method)

ANALOGY มโนภาพในชีวิตจริง: ชาเลนจ์ออมเงิน 100 วัน (100-Day Savings Challenge)
วันที่ 1 หยอด 1 บาท, วันที่ 2 หยอด 2 บาท, ... วันที่ 100 หยอด 100 บาท ครบ 100 วันจะมีเงินกี่บาท?
เกาส์ (Gauss) จับคู่ วันแรก + วันสุดท้าย: $1 + 100 = 101$, คู่ถัดไป $2 + 99 = 101$, ทั้งหมดมี 50 คู่ ($100/2$ คู่)
$$\text{ยอดเงินรวม} = 50 \times 101 = \mathbf{5,050 \text{ บาท}} \implies \text{สูตร: } S_n = \frac{n}{2}(a_1 + a_n)$$
FORMULA สูตรผลรวมอนุกรมเลขคณิต $n$ พจน์แรก
$$\mathbf{S_n = \frac{n}{2}(a_1 + a_n) = \frac{n}{2}[2a_1 + (n - 1)d]}$$ • รูปแรกเมื่อทราบ $a_n$, รูปหลังเมื่อทราบ $d$
SPECIAL CASE สูตรผลรวม 1 ถึง n ในชีวิตประจำวัน
$$\mathbf{\sum_{i=1}^n i = 1 + 2 + \dots + n = \frac{n(n+1)}{2}}$$
มโนภาพ: เกาส์จับคู่หัว-ท้าย $1+100=101$ ได้ 50 คู่ รวมเป็น 5,050 บาท

Concept 2.5

อนุกรมเรขาคณิตจำกัด (Finite Geometric Series)

ANALOGY มโนภาพในชีวิตจริง: การสะสมเงินออมแบบทวีคูณ (Doubling Savings Plan)
สมมุติวางแผนออมเงินรายสัปดาห์: สัปดาห์แรกออม 100 บาท ($a_1 = 100$) สัปดาห์ถัดไปออมเพิ่มเป็น 2 เท่า ($r = 2$):
สัปดาห์ที่ 1 ถึง 4 ออม: $100, 200, 400, 800$ บาท $\implies$ ยอดรวมสะสมคือ $S_4 = 100 + 200 + 400 + 800 = \mathbf{1,500 \text{ บาท}}$
เมื่อคำนวณด้วยสูตร: $S_4 = \frac{100(2^4 - 1)}{2 - 1} = \frac{100(16 - 1)}{1} = \mathbf{1,500 \text{ บาท}}$ (คำนวณสะดวกรวดเร็ว แม้มีหลายสิบงวด)
FORMULA สูตรผลรวมอนุกรมเรขาคณิต $n$ พจน์แรก
เมื่อ $r \neq 1$: $$\mathbf{S_n = \frac{a_1(1 - r^n)}{1 - r} = \frac{a_1(r^n - 1)}{r - 1}} \qquad \text{(กรณี } r = 1 \text{ จะได้ } S_n = n a_1)$$ • ถ้า $r > 1$ นิยมใช้รูปขวาเพื่อให้เศษและส่วนเป็นบวก
PROOF ที่มาของสูตร (Algebraic Subtraction)
(1) $S_n = a_1 + a_1 r + a_1 r^2 + \dots + a_1 r^{n-1}$
(2) $r S_n = a_1 r + a_1 r^2 + \dots + a_1 r^n$
(1) - (2): $S_n(1 - r) = a_1(1 - r^n) \implies \mathbf{S_n = \frac{a_1(1 - r^n)}{1 - r}}$
นำ $S_n - rS_n$ หักล้างพจน์ตรงกลางออกทั้งหมด

อนุกรมอนันต์ การลู่เข้าและการลู่ออกInfinite Geometric Series: Convergence vs Divergence

Concept 3.1

นิยามอนุกรมอนันต์และลิมิตของผลบวกย่อย ($S_\infty$)

DEF นิยามอนุกรมอนันต์ (Infinite Series)
เมื่อพิจารณาผลบวกของสมาชิกในลำดับต่อไปเรื่อยๆ อย่างไม่มีที่สิ้นสุด ($n \to \infty$): $$\mathbf{S_\infty = \sum_{i=1}^\infty a_i = a_1 + a_2 + a_3 + \dots = \lim_{n \to \infty} S_n}$$ โดยที่ $S_n = a_1 + a_2 + \dots + a_n$ เรียกว่า ผลบวกย่อยลำดับที่ $n$ (Sequence of Partial Sums)
QUESTION เราสามารถบวกตัวเลขไปเรื่อยๆ จนถึงอนันต์ได้หรือไม่?
• ลู่เข้า (Convergent): ผลบวกย่อย $S_n$ วิ่งเข้าใกล้ค่าคงที่จำกัดค่าหนึ่ง
• ลู่ออก (Divergent): $S_n$ โตขึ้นไร้ขอบเขต หรือแกว่งไปมา
INSIGHT ความน่าทึ่งของคณิตศาสตร์
การบวกจำนวนอนันต์ตัว ไม่จำเป็นต้องได้ $\infty$ เสมอไป หากแต่ละพจน์ เล็กลงเร็วพอ ผลรวมจะหยุดนิ่งที่ค่าจำกัดค่าหนึ่ง
🎯 ผลบวกย่อย $S_n$ วิ่งประชิดเส้นกำกับ $S_\infty = 24$
เส้นประสีแดง = ลิมิต $L=24$ เมื่อ $n \to \infty$

Concept 3.2

ภาวะลู่เข้า (Convergence เมื่อ $|r| < 1$)

ANALOGY มโนภาพในชีวิตจริง: การแบ่งเค้กทีละครึ่ง / กองทุนจ่ายเงินปันผลถาวร (Perpetuity)
สมมุติมีเค้ก 1 ชิ้น วันนี้ตัดกินครึ่งหนึ่ง ($\frac{1}{2}$), วันพรุ่งนี้กินครึ่งหนึ่งของที่เหลือ ($\frac{1}{4}$), วันถัดไป ($\frac{1}{8}$) ต่อเนื่องไม่สิ้นสุด:
ผลรวมเค้กที่กินทั้งหมดคือ $\frac{1}{2} + \frac{1}{4} + \frac{1}{8} + \dots = \mathbf{1 \text{ ชิ้นพอดี}}$ (ไม่มีทางเกิน 1 ชิ้น แม้บวกไปอนันต์งวด!)
FORMULA สูตรผลรวมอนุกรมเรขาคณิตอนันต์
เมื่อ $-1 < r < 1$ (หรือ $|r| < 1$) จะได้ว่า $r^n \to 0$ เมื่อ $n \to \infty$
$$\mathbf{S_\infty = \frac{a_1}{1 - r}}$$ ผลรวมจะลู่เข้าสู่ค่าคงที่จำกัดค่าหนึ่งเสมอ (เส้นกำกับแนวนอน)
FINANCE การประยุกต์ในทางการเงิน
สูตรนี้คือที่มาของการประเมินมูลค่า กองทุนเงินปันผลถาวร (Perpetuity) และการคิดลดมูลค่าปัจจุบัน (Present Value)
มโนภาพการแบ่งเค้กอนันต์: $\frac{1}{2} + \frac{1}{4} + \frac{1}{8} + \dots = 1$ ก้อนเต็ม

Concept 3.3

ภาวะลู่ออก (Divergence เมื่อ $|r| \ge 1$)

DIVERGE พฤติกรรมเมื่อ $|r| \ge 1$ (ลู่ออก)
เมื่ออัตราส่วนร่วม $r \ge 1$ หรือ $r \le -1$ พจน์ต่อๆ ไปจะไม่เล็กลง ส่งผลให้ผลรวมย่อย $S_n$ ไม่สามารถลู่เข้าหาค่าใดค่าหนึ่งได้
CASE 1 กรณี $r \ge 1$: โตขึ้นไร้ขอบเขต ($S_n \to \infty$)
เช่น $1 + 2 + 4 + 8 + 16 + \dots$ ($r = 2$)
• พจน์ต่อๆ ไปใหญ่ขึ้นเรื่อยๆ ยอดรวมสะสมจึงพุ่งทะยานสู่ **อนันต์ ($\infty$)**
💥 ระเบิดสู่อนันต์ ($r = 2$)
CASE 2 กรณี $r \le -1$: แกว่งกวัดไม่คงที่ (Oscillation)
เช่น $1 - 1 + 1 - 1 + 1 - \dots$ ($r = -1$)
• ผลบวกย่อยจะแกว่งสลับ: $S_1=1, S_2=0, S_3=1, S_4=0, \dots$
💥 กวัดแกว่งสลับค่า ($r = -1$)

Example 3.4

ตัวอย่างที่ 9 — การคำนวณผลรวมอนันต์และการแปลงทศนิยมซ้ำ

EX 1 ผลรวมอนันต์ของ $12 + 6 + 3 + 1.5 + \dots$
1. พจน์แรก $a_1 = 12$, อัตราส่วนร่วม $r = \frac{6}{12} = \mathbf{0.5}$
2. $|0.5| < 1 \implies$ ลู่เข้า หาผลรวมได้

Visual Concept 3.5

แผนภาพเปรียบเทียบพฤติกรรม: ลู่เข้า (Converge) vs ลู่ออก (Diverge)

SUMMARY สรุปเกณฑ์ตัดสินอนุกรมเรขาคณิตอนันต์
พิจารณาค่าอัตราส่วนร่วม $r$ เพียงตัวเดียวเท่านั้น:
• $|r| < 1$ (ช่วง $-1 < r < 1$): ลู่เข้า (Convergent) ผลรวมเข้าใกล้ $\frac{a_1}{1-r}$ ยิ่งบวกเพิ่มยิ่งนิ่ง
• $r \ge 1$: ลู่ออก (Divergent) พุ่งขึ้นฟ้าสู่อนันต์ ($+\infty$)
• $r \le -1$: ลู่ออก (Divergent) แกว่งขึ้นๆ ลงๆ อย่างรุนแรงจนหาค่าไม่ได้

ฟังก์ชันเวียนเกิดในชีวิตประจำวันRecursive Functions & Recurrence Relations

Concept 4.1

นิยามฟังก์ชันเวียนเกิดและโครงสร้าง 2 ส่วนสำคัญ

ANALOGY มโนภาพในชีวิตจริง: ยอดเงินในบัญชีดอกเบี้ยทบต้น (Compound Interest)
สมมุติยอดเงินในบัญชีสิ้นปีที่ $n$ คือ $B(n)$ ดอกเบี้ยทบต้น $10\%$ ต่อปี ($1.10$) จากเงินต้นตั้งต้น 10,000 บาท:
• ขั้นตอนเวียนเกิด (Recursive Step): $B(n) = B(n - 1) \times 1.10$ (ยอดเงินปีนี้คำนวณจากยอดเงินปีก่อนหน้า)
• กรณีฐาน (Base Case): $B(0) = 10,000$ บาท (หากไม่มีเงินต้นตั้งต้น จะคำนวณยอดเงินปีใดๆ ไม่ได้!)
PART 1 1. กรณีฐาน (Base Case)
• เงื่อนไขหรือค่าเริ่มต้นที่ทราบแน่นอน เช่น เงินต้นตั้งต้น ($B(0) = 10,000$)
• สำคัญมาก: หากไม่มี Base Case จะเกิดการคำนวณวนซ้ำไม่รู้จบ

• กรณีฐาน: $B(0) = 10,000$
• ขั้นตอนเวียนเกิด: $B(n) = \mathbf{1.10 \times B(n-1)}$

$B(3) = 1.10 \times B(2) = 10,000(1.10)^3 = 13,310$
$$\mathbf{\implies B(n) = 10,000 \times (1.10)^n}$$

Example 4.3

ตัวอย่างที่ 11 — แฟกทอเรียล ($n!$) กับการจัดลำดับสิ่งของในชีวิตประจำวัน

DEF นิยามฟังก์ชันเวียนเกิดของแฟกทอเรียล
$$\mathbf{n! = \begin{cases} 1 & \text{เมื่อ } n = 0 \text{ หรือ } n = 1 \quad \text{(Base Case)} \\ n \times (n - 1)! & \text{เมื่อ } n \ge 2 \quad \text{(Recursive Step)} \end{cases}}$$
TRACE การคลี่ขั้นตอนคำนวณ $4!$
• $4! = 4 \times 3!$
• $3! = 3 \times 2!$
• $2! = 2 \times 1!$
• $1! = 1$ (ถึง Base Case $\implies$ ส่งค่ากลับ!)
• $4! = 4 \times (3 \times (2 \times 1)) = \mathbf{24}$
REAL LIFE การประยุกต์: การจัดลำดับสิ่งของ
• จัดคน 4 คนเข้าแถวได้ $4! = \mathbf{24 \text{ แบบ}}$
• จัดหนังสือ 5 เล่มบนชั้นได้ $5! = 120 \text{ แบบ}$
การคลี่ฟังก์ชันแฟกทอเรียลแล้วส่งผลคูณกลับ
