ยูเนียน (Union): รวมกัน

นิยาม A ∪ B = {x | x ∈ A หรือ x ∈ B} — สมาชิกที่อยู่ใน A หรือ B (หรือทั้งคู่)
ตัวอย่าง: A = {1,2,3,4}, B = {3,4,5,6}
A ∪ B = {1,2,3,4,5,6}
  • 3 และ 4 อยู่ทั้งสองเซต แต่เขียน ครั้งเดียว
  • A ∪ ∅ = A (Identity) · A ∪ U = U (Domination) · A ⊆ A ∪ B เสมอ
พื้นที่แรเงา = A ∪ B

อินเตอร์เซกชัน (Intersection): ส่วนที่ซ้อนทับ

นิยาม A ∩ B = {x | x ∈ A และ x ∈ B} — สมาชิกที่อยู่ ทั้งสองเซตพร้อมกัน
ตัวอย่าง: A = {2,4,6,8,10}, B = {3,6,9,12}
A ∩ B = {6}
Disjoint ถ้า A ∩ B = ∅ เรียก A, B ว่า เซตแยกกัน (Disjoint Sets)
พื้นที่แรเงา = A ∩ B

ผลต่าง (Set Difference): อยู่ซ้ายแต่ไม่อยู่ขวา

นิยาม A − B = {x | x ∈ A และ x ∉ B} (เขียน A \ B ก็ได้)
ตัวอย่าง: A = {a,b,c,d,e}, B = {b,d,f}
A − B = {a, c, e}

พื้นที่แรเงา = A − B (พระจันทร์เสี้ยวซ้าย)

คอมพลีเมนต์ (Complement): ทุกอย่างที่เหลือ

นิยาม Ac = {x ∈ U | x ∉ A} = U − A (เขียน Ā หรือ A′ ก็ได้)
ตัวอย่าง: U = {1,…,8}, A = {2,4,6,8} → Ac = {1,3,5,7}
  • A ∪ Ac = U และ A ∩ Ac = ∅
  • (Ac)c = A (Double Complement)
ระวัง คอมพลีเมนต์ ขึ้นกับ U: เซต A เดียวกัน ถ้าเปลี่ยน U ผลลัพธ์ Ac ก็เปลี่ยน — ต้องกำหนด U ก่อนเสมอ
พื้นที่แรเงา = Ac

Laws 1/2

กฎพีชคณิตของเซต (1/2)

เทียบกับ "กฎพีชคณิตของประพจน์" สัปดาห์ที่ 2 — โครงสร้างเดียวกันทุกข้อ
ชื่อกฎรูปของเซต
นิจพล (Idempotent)A ∪ A = A · A ∩ A = A
เอกลักษณ์ (Identity)A ∪ ∅ = A · A ∩ U = A
ครอบงำ (Domination)A ∪ U = U · A ∩ ∅ = ∅
สลับที่ (Commutative)A ∪ B = B ∪ A · A ∩ B = B ∩ A
เปลี่ยนกลุ่ม (Associative)(A ∪ B) ∪ C = A ∪ (B ∪ C)
สังเกต: แทน ∨ → ∪, ∧ → ∩, F → ∅, T → U จากกฎประพจน์ได้เลย

Laws 2/2

กฎพีชคณิตของเซต (2/2)

ชื่อกฎรูปของเซต
แจกแจง (Distributive)A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
ดูดกลืน (Absorption)A ∪ (A ∩ B) = A · A ∩ (A ∪ B) = A
คอมพลีเมนต์ (Complement)A ∪ Ac = U · A ∩ Ac = ∅ · (Ac)c = A
เดอมอร์แกน (De Morgan)(A ∪ B)c = Ac ∩ Bc · (A ∩ B)c = Ac ∪ Bc
สำคัญ กฎชุดนี้ + กฎชุดประพจน์ + พีชคณิตบูลีน (บทที่ 6) คือ "กฎเดียวกันในสามเสื้อคลุม"

Proof Technique

ตัวอย่าง: พิสูจน์กฎดูดกลืน A ∪ (A ∩ B) = A

ใช้ double inclusion (พิสูจน์สองทิศทาง)
ทิศทาง ⊆ สมมติ x ∈ A ∪ (A ∩ B)
· กรณี x ∈ A — จบทันที
· กรณี x ∈ A ∩ B — โดยนิยามของ ∩ ได้ x ∈ A เช่นกัน
ดังนั้นทุกกรณี x ∈ A
ทิศทาง ⊇ สมมติ x ∈ A
แล้ว x ∈ A ∪ X สำหรับทุกเซต X โดยนิยามของ ∪
ดังนั้น x ∈ A ∪ (A ∩ B)
สรุป ทั้งสองทิศทางเป็นจริง ดังนั้น A ∪ (A ∩ B) = A ∎

กฎเดอมอร์แกนสำหรับเซตDe Morgan's Laws

De Morgan

กฎเดอมอร์แกน De Morgan's Laws

กฎ 2 ข้อ 1) (A ∪ B)c = Ac ∩ Bc — "ไม่ (A หรือ B)" = "(ไม่ A) และ (ไม่ B)"
2) (A ∩ B)c = Ac ∪ Bc — "ไม่ (A และ B)" = "(ไม่ A) หรือ (ไม่ B)"
ตรรกศาสตร์ (บทที่ 1)เซต (บทที่ 2)
¬(p ∨ q) ≡ ¬p ∧ ¬q(A ∪ B)c = Ac ∩ Bc
¬(p ∧ q) ≡ ¬p ∨ ¬q(A ∩ B)c = Ac ∪ Bc
SPACE คลิกดูตารางเทียบกับบทที่ 1
หัวใจ นิเสธ "ทะลุ" วงเล็บแล้ว สลับ ∪ ↔ ∩ (ตั้งชื่อตาม Augustus De Morgan, 1806–1871)
คณิตศาสตร์สำหรับคอมพิวเตอร์◆บทที่ 2 ทฤษฎีเซต
Visual Proof

ยืนยันด้วยแผนภาพเวนน์: (A ∪ B)c = Ac ∩ Bc

(A ∪ B)c — นอกวงทั้งสอง
Ac ∩ Bc — นอก A "และ" นอก B
พื้นที่แรเงา เหมือนกันทุกจุด ⇒ สองนิพจน์เท่ากัน (แผนภาพช่วย "เห็น" แต่การพิสูจน์จริงใช้เชิงสมาชิก → หน้าถัดไป)
คณิตศาสตร์สำหรับคอมพิวเตอร์◆บทที่ 2 ทฤษฎีเซต
Element-wise Proof

พิสูจน์เชิงสมาชิก: (A ∪ B)c = Ac ∩ Bc

ไล่สมมูลทีละขั้น (แต่ละขั้นย้อนกลับได้ จึงได้ทั้งสองทิศทางพร้อมกัน)
x ∈ (A ∪ B)c
⟺x ∉ A ∪ B
⟺¬(x ∈ A หรือ x ∈ B)
⟺¬(x ∈ A) และ ¬(x ∈ B)   ← เดอมอร์แกนของประพจน์!
⟺x ∈ Ac และ x ∈ Bc
⟺x ∈ Ac ∩ Bc
ข้อสังเกต ขั้นตอนสำคัญคือการ "ยืม" กฎเดอมอร์แกนของ ประพจน์ มาใช้ — ทฤษฎีเซตสร้างบนตรรกศาสตร์อย่างแท้จริง

  2. A ∪ (B − A)  (คำใบ้: เริ่มจาก B − A = B ∩ Ac)
เฉลย 1) (A ∪ B) ∩ (A ∪ Bc) = A ∪ (B ∩ Bc) (แจกแจงย้อนกลับ) = A ∪ ∅ (คอมพลีเมนต์) = A (เอกลักษณ์)
2) A ∪ (B − A) = A ∪ (B ∩ Ac) (สูตรผลต่าง) = (A ∪ B) ∩ (A ∪ Ac) (แจกแจง) = (A ∪ B) ∩ U (คอมพลีเมนต์) = A ∪ B (เอกลักษณ์)
