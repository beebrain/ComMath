\vspace{1em}
\noindent\textbf{วัตถุประสงค์การเรียนรู้ประจำบท}\\[0.3em]
\noindent เมื่อนักศึกษาเรียนบทนี้จบแล้ว นักศึกษาจะสามารถ:
\begin{enumerate}[topsep=0.3em, itemsep=0.25em]
    \item อธิบายความหมายของความสัมพันธ์ (Relation) และผลคูณคาร์ทีเซียนได้
    \item ระบุคุณสมบัติของความสัมพันธ์ เช่น Reflexive, Symmetric, Transitive ได้
    \item ระบุและจำแนกประเภทของฟังก์ชัน เช่น Injective, Surjective, Bijective ได้
    \item ใช้การประกอบฟังก์ชัน (Composition) และหาฟังก์ชันผกผันได้
    \item ประยุกต์ใช้ความสัมพันธ์และฟังก์ชันในบริบทของโปรแกรมคอมพิวเตอร์ได้
\end{enumerate}

\vspace{1em}
\noindent\textbf{หัวข้อที่สอน}\\[0.3em]
\begin{enumerate}[topsep=0.3em, itemsep=0.25em]
    \item ผลคูณคาร์ทีเซียนและนิยามของความสัมพันธ์
    \item คุณสมบัติของความสัมพันธ์ (สะท้อน สมมาตร เป็นปฏิสมมาตร ถ่ายทอด)
    \item ความสัมพันธ์สมมูล (Equivalence Relations)
    \item ความสัมพันธ์อันดับบางส่วน (Partial Ordering Relations)
    \item การดำเนินการและการปิดคุณสมบัติของความสัมพันธ์ (Operations and Closures)
    \item ฟังก์ชัน: นิยาม ประเภท การประกอบ และฟังก์ชันผกผัน
    \item การประยุกต์ในวิทยาการคอมพิวเตอร์
\end{enumerate}
