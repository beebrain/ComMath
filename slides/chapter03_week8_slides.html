Definition

นิยามฟังก์ชัน และความแตกต่างจากความสัมพันธ์

DEF ฟังก์ชัน (Function $f: A \to B$)
ความสัมพันธ์ $f$ จาก $A$ ไป $B$ จะเป็น ฟังก์ชัน ก็ต่อเมื่อ: $$\mathbf{\forall x \in A, \exists! y \in B \text{ such that } (x, y) \in f}$$ เงื่อนไขสำคัญ 2 ประการ:
1. สมาชิกต้นทาง $x \in A$ ทุกตัว ต้องถูกนำมาจับคู่
2. สมาชิกต้นทางแต่ละตัวจับคู่กับปลายทางได้ เพียงตัวเดียวเท่านั้น (Uniqueness)
RULE กฎการตรวจสอบ (Vertical Line / Arrow Test)
• แผนภาพลูกศร: โหนดต้นทางทุกโหนดต้องมีลูกศรพุ่งออก 1 เส้นพอดี (ห้ามไม่มี และห้ามแตก 2 เส้น)
• ในกราฟ: เส้นแนวตั้งลากผ่านกราฟต้องตัดได้ ไม่เกิน 1 จุด เสมอ
EX เปรียบเทียบตัวอย่าง
ให้ $A = \{1, 2, 3\}$ และ $B = \{a, b, c\}$

• $f_1 = \{(1, a), (2, b), (3, a)\}$ $\implies$ ✓ เป็นฟังก์ชัน (ต้นทางจับครบ และตัวหน้าไม่ซ้ำ)

• $f_2 = \{(1, a), (1, b), (2, c), (3, a)\}$ $\implies$ ✗ ไม่เป็นฟังก์ชัน (เลข 1 จับคู่ 2 ตัวพร้อมกัน!)

• $f_3 = \{(1, a), (2, b)\}$ $\implies$ ✗ ไม่เป็นฟังก์ชัน (เลข 3 ไม่ได้ถูกจับคู่!)
นิยามฟังก์ชัน4091606 · CH03-W08
Structure

โดเมน โคโดเมน (Codomain) และเรนจ์ของฟังก์ชัน

DEF ส่วนประกอบของฟังก์ชัน $f: A \to B$
• โดเมน (Domain $\operatorname{Dom}(f)$): เซตต้นทางทั้งหมด นั่นคือ $\operatorname{Dom}(f) = A$
• โคโดเมน (Codomain): เซตปลายทางทั้งหมด $B$ ซึ่งกำหนดขอบเขตของผลลัพธ์ที่เป็นไปได้ (เหมือน Data Type เช่น \texttt{int, float})
• เรนจ์ (Range $\operatorname{Ran}(f)$ หรือ ภาพ $f(A)$): เซตของค่าผลลัพธ์จริงที่ถูกจับคู่: $$\mathbf{\operatorname{Ran}(f) = \{f(x) \mid x \in A\} \subseteq B}$$
NOTE ข้อควรระวัง: โคโดเมน $\neq$ เรนจ์ เสมอไป
กำหนด $f: \mathbb{R} \to \mathbb{R}$ โดย $f(x) = x^2$

• โดเมน $= \mathbb{R}$ (จำนวนจริงทั้งหมด)
• โคโดเมน $= \mathbb{R}$ (จำนวนจริงทั้งหมด)
• เรนจ์ $= [0, \infty)$ (เฉพาะจำนวนจริงที่ไม่เป็นลบเท่านั้น!)

เรนจ์จึงเป็นเพียงเซตย่อยของโคโดเมนเท่านั้น ($\operatorname{Ran}(f) \subseteq \text{Codomain}$)
โดเมน โคโดเมน & เรนจ์4091606 · CH03-W08
Classification

ประเภทของฟังก์ชัน (Injective, Surjective, Bijective)

1 หนึ่งต่อหนึ่ง (Injective)
$$\forall a, b \in A, f(a) = f(b) \implies a = b$$ • สมาชิกปลายทางแต่ละตัว โดนจับคู่ไม่เกิน 1 ครั้ง (ห้ามมีลูกศรชนกัน)
• การทดสอบ: ลากเส้นแนวนอนตัดกราฟได้ไม่เกิน 1 จุด (Horizontal Line Test)
2 ทั่วถึง (Surjective)
$$\forall y \in B, \exists x \in A, f(x) = y$$ • สมาชิกในโคโดเมน $B$ ทุกตัว ต้องถูกจับคู่อย่างน้อย 1 ครั้ง
• เงื่อนไขเทียบเท่า: เรนจ์เท่ากับโคโดเมนพอดี ($\operatorname{Ran}(f) = B$)
3 หนึ่งต่อหนึ่งทั่วถึง (Bijective)
$$\mathbf{\text{Bijective} = \text{Injective} \land \text{Surjective}}$$ • มีการจับคู่แบบหนึ่งต่อหนึ่งอย่างสมบูรณ์แบบ
• เป็น เงื่อนไขจำเป็นและเพียงพอ สำหรับการมี ฟังก์ชันผกผัน ($f^{-1}$)

Composition & Inverse

การประกอบฟังก์ชัน และฟังก์ชันผกผัน

COMP ฟังก์ชันประกอบ (Composite Function)
ให้ $g: A \to B$ และ $f: B \to C$ ฟังก์ชันประกอบ $f \circ g: A \to C$ คือ: $$\mathbf{(f \circ g)(x) = f(g(x))}$$ • นำ $x$ ป้อนให้ $g$ ก่อน ได้ผลลัพธ์ $g(x)$ แล้วนำไปป้อนต่อให้ $f$
• สมบัติการสลับที่: โดยทั่วไป $f \circ g \neq g \circ f$
INV ฟังก์ชันผกผัน (Inverse Function $f^{-1}$)
ถ้า $f: A \to B$ เป็น Bijective จะมีฟังก์ชันผกผัน $f^{-1}: B \to A$: $$\mathbf{f^{-1}(y) = x \iff f(x) = y}$$ $$(f^{-1} \circ f)(x) = x \quad \text{และ} \quad (f \circ f^{-1})(y) = y$$
EX ตัวอย่างการคำนวณ
กำหนด $f(x) = 2x + 3$ และ $g(x) = x^2 - 1$

1. $(f \circ g)(x) = f(x^2 - 1) = 2(x^2 - 1) + 3 = \mathbf{2x^2 + 1}$
2. $(g \circ f)(x) = g(2x + 3) = (2x + 3)^2 - 1 = \mathbf{4x^2 + 12x + 8}$
3. หา $f^{-1}(x)$: ให้ $y = 2x + 3 \implies 2x = y - 3 \implies \mathbf{f^{-1}(x) = \frac{x - 3}{2}}$
การประกอบ & ฟังก์ชันผกผัน4091606 · CH03-W08
Special Functions 1

ฟังก์ชันปัดเศษลง (Floor) และปัดเศษขึ้น (Ceiling)

DEF Floor ($\lfloor x \rfloor$) & Ceiling ($\lceil x \rceil$)
• ฟังก์ชันพื้น (Floor $\lfloor x \rfloor$): จำนวนเต็มที่มากที่สุดที่ $\le x$
$\lfloor 3.8 \rfloor = 3, \quad \lfloor 3.0 \rfloor = 3, \quad \lfloor -3.2 \rfloor = -4$

• ฟังก์ชันเพดาน (Ceiling $\lceil x \rceil$): จำนวนเต็มที่น้อยที่สุดที่ $\ge x$
$\lceil 3.2 \rceil = 4, \quad \lceil 3.0 \rceil = 3, \quad \lceil -3.8 \rceil = -3$
COMP การประยุกต์ในวิทยาการคอมพิวเตอร์
1. การแบ่งหน้าข้อมูล (Pagination):
มีข้อมูล $N = 127$ รายการ แสดงหน้าละ $S = 10$ รายการ
จำนวนหน้าทั้งหมด $= \lceil N / S \rceil = \lceil 127 / 10 \rceil = \lceil 12.7 \rceil = \mathbf{13 \text{ หน้า}}$

2. การจัดสรรบล็อกหน่วยความจำ (Block Allocation):
ไฟล์ขนาด 4,500 ไบต์ บล็อกละ 1,024 ไบต์
จำนวนบล็อก $= \lceil 4500 / 1024 \rceil = \lceil 4.39 \rceil = \mathbf{5 \text{ บล็อก (5,120 ไบต์)}}$

Special Functions 2

ฟังก์ชันมอดุโล (Modulo) และฟังก์ชันแฮช (Hash Function)

DEF ฟังก์ชันมอดุโล (Modulo $a \bmod m$)
ให้ $a \in \mathbb{Z}$ และ $m \in \mathbb{Z}^+$:
$$a \bmod m = r \quad \text{โดยที่ } 0 \le r < m \text{ และ } a = qm + r$$ • $17 \bmod 5 = 2 \quad (17 = 3 \cdot 5 + 2)$
• $-8 \bmod 3 = 1 \quad (-8 = -3 \cdot 3 + 1)$
• Circular Buffer / Round-Robin: $(\text{index} + 1) \bmod N$
HASH ฟังก์ชันแฮช (Hash Function)
แปลงคีย์ข้อมูลขนาดใหญ่ $k$ ให้เป็นดัชนีช่องตารางขนาดจำกัด $m$: $$\mathbf{h(k) = k \bmod m}$$ • การชนกันของแฮช (Hash Collision): เกิดขึ้นเมื่อ $k_1 \neq k_2$ แต่ $h(k_1) = h(k_2)$ (เช่น $h(15) = 15 \bmod 7 = 1$ และ $h(22) = 22 \bmod 7 = 1$)

Special Functions 3

ฟังก์ชันแบบเรียกซ้ำ (Recursive Functions & Call Stack)

DEF 2 ส่วนประกอบของฟังก์ชันเรียกซ้ำ
1. กรณีฐาน (Base Case): เงื่อนไขหยุดที่ให้คำตอบทันทีโดยไม่เรียกซ้ำ
2. ขั้นตอนการเรียกซ้ำ (Recursive Step): ลดขนาดของปัญหาลงทีละขั้นสู่กรณีฐาน
EX แฟกทอเรียล (Factorial $n!$)
$$f(n) = \begin{cases} 1 & n = 0 \text{ (Base Case)} \\ n \cdot f(n-1) & n \ge 1 \text{ (Recursive)} \end{cases}$$
STACK ลำดับการทำงานบนหน่วยความจำ (Call Stack)
$f(3) = 3 \cdot f(2)$
$\quad \to f(2) = 2 \cdot f(1)$
$\quad\quad \to f(1) = 1 \cdot f(0)$
$\quad\quad\quad \to f(0) = 1 \quad \text{(Base Hit!)}$
$\quad\quad \leftarrow 1 \cdot 1 = 1$
$\quad \leftarrow 2 \cdot 1 = 2$
$\leftarrow 3 \cdot 2 = \mathbf{6}$
หากไม่มี Base Case จะเกิดข้อผิดพลาด Stack Overflow!
