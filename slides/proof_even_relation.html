การพิสูจน์ความสัมพันธ์สมมูล

เจาะลึกขั้นตอนการพิสูจน์ความสัมพันธ์ $a + b$ เป็นเลขคู่ และ คอนกรูเอนซ์มอดุโล $m$ ($a \equiv b \pmod m$) บนระบบจำนวนเต็ม $\mathbb{Z}$ อย่างเป็นขั้นตอนและรัดกุมตามหลักคณิตศาสตร์

📋
โจทย์และนิยามเริ่มต้น
Problem Formulation & Definition

กำหนดให้ $R$ เป็นความสัมพันธ์ทวิภาคบนเซตของจำนวนเต็ม $\mathbb{Z}$ โดยมีเงื่อนไขดังนี้

$$a \, R \, b \iff a + b \text{ เป็นจำนวนคู่} \iff \exists k \in \mathbb{Z}, \, a + b = 2k$$

เป้าหมาย: จงพิสูจน์ว่า $R$ เป็น ความสัมพันธ์สมมูล (Equivalence Relation) บน $\mathbb{Z}$ ซึ่งจะต้องแสดงให้เห็นจริงครบทั้ง 3 สมบัติ ได้แก่

1. สะท้อน (Reflexive) 2. สมมาตร (Symmetric) 3. ถ่ายทอด (Transitive)
1
1. การพิสูจน์สมบัติสะท้อน (Reflexive Property)
$\forall a \in \mathbb{Z}, (a, a) \in R$
  • ให้ $a$ เป็นจำนวนเต็มใด ๆ ใน $\mathbb{Z}$
  • พิจารณาผลบวกของ $a$ กับตัวเอง:
    $$a + a = 2a$$
  • เนื่องจาก $a \in \mathbb{Z}$ จะได้ว่า $2a$ อยู่ในรูปของผลคูณระหว่าง $2$ กับจำนวนเต็ม ทำให้ $a + a$ เป็นจำนวนคู่เสมอ
  • ส่งผลให้ $(a, a) \in R$ สำหรับทุก $a \in \mathbb{Z}$
✓ สรุป: $R$ มีสมบัติสะท้อนบน $\mathbb{Z}$ $\blacksquare$

ตัวอย่างเชิงตัวเลข: ถ้า $a = 5$ จะได้ $5 + 5 = 10 = 2(5)$ (เป็นคู่) หรือถ้า $a = -4$ จะได้ $(-4) + (-4) = -8 = 2(-4)$ (เป็นคู่เสมอ)

2
2. การพิสูจน์สมบัติสมมาตร (Symmetric Property)
$\forall a, b \in \mathbb{Z}, (a, b) \in R \implies (b, a) \in R$
  • ให้ $a, b \in \mathbb{Z}$ และสมมุติว่า $(a, b) \in R$
  • จากนิยาม จะมีจำนวนเต็ม $k \in \mathbb{Z}$ ที่ทำให้:
    $$a + b = 2k$$
  • โดย สมบัติการสลับที่ของการบวก (Commutative Property of Addition) บนจำนวนเต็ม:
    $$b + a = a + b = 2k$$
  • เนื่องจาก $2k$ เป็นจำนวนคู่ จึงได้ว่า $b + a$ เป็นจำนวนคู่ด้วย
  • ส่งผลให้ $(b, a) \in R$
✓ สรุป: $R$ มีสมบัติสมมาตร $\blacksquare$

ตัวอย่างเชิงตัวเลข: เลือก $a = 3, b = 7$ จะได้ $3 + 7 = 10$ เมื่อสลับที่ $7 + 3 = 10$ ยังคงได้ผลรวมเป็น 10 เท่าเดิมทุกประการ

3
3. การพิสูจน์สมบัติถ่ายทอด (Transitive Property)
$\forall a, b, c \in \mathbb{Z}, [(a, b) \in R \land (b, c) \in R] \implies (a, c) \in R$
  • ให้ $a, b, c \in \mathbb{Z}$ โดยสมมุติว่า $(a, b) \in R$ และ $(b, c) \in R$
  • จะมีจำนวนเต็ม $k_1, k_2 \in \mathbb{Z}$ ที่ทำให้:
    $$a + b = 2k_1 \quad \text{และ} \quad b + c = 2k_2$$
  • นำสมการทั้งสองมาบวกเข้าด้วยกัน:
    $$(a + b) + (b + c) = 2k_1 + 2k_2$$ $$a + 2b + c = 2(k_1 + k_2)$$ $$a + c = 2(k_1 + k_2) - 2b$$ $$a + c = 2(k_1 + k_2 - b)$$
  • เนื่องจาก $k_1, k_2, b \in \mathbb{Z}$ จะได้ว่า $(k_1 + k_2 - b)$ เป็นจำนวนเต็ม ให้เป็น $k_3 \in \mathbb{Z}$
  • จะได้สมการ $a + c = 2k_3$ ซึ่งแสดงว่า $a + c$ เป็นจำนวนคู่ ดังนั้น $(a, c) \in R$
✓ สรุป: $R$ มีสมบัติถ่ายทอด $\blacksquare$

ตัวอย่างเชิงตัวเลข: เลือก $a = 3, b = 7, c = 11$ จะได้ $3+7 = 10$ (คู่), $7+11 = 18$ (คู่) $\implies 3+11 = 14$ (เป็นจำนวนคู่เช่นเดียวกัน)

🗂️
คลาสสมมูล (Equivalence Classes) และการแบ่งกั้นเซต $\mathbb{Z}$
Partitions of $\mathbb{Z}$ under Parity Equivalence

เนื่องจาก $R$ มีครบทั้ง 3 สมบัติ จึงเป็น ความสัมพันธ์สมมูล และแบ่งจำนวนเต็ม $\mathbb{Z}$ ออกเป็น 2 คลาสสมมูล ที่ไม่ซ้อนทับกันเลย:

1. คลาสของจำนวนคู่ $[0]$:
$$[0] = \{x \in \mathbb{Z} \mid 0 + x \text{ เป็นคู่}\} = 2\mathbb{Z}$$ $$[0] = \{\dots, -6, -4, -2, 0, 2, 4, 6, \dots\}$$
2. คลาสของจำนวนคี่ $[1]$:
$$[1] = \{x \in \mathbb{Z} \mid 1 + x \text{ เป็นคู่}\} = 2\mathbb{Z} + 1$$ $$[1] = \{\dots, -5, -3, -1, 1, 3, 5, 7, \dots\}$$

• ผลกั้นเซต (Partition): $[0] \cup [1] = \mathbb{Z}$ และ $[0] \cap [1] = \emptyset$ (ทุกจำนวนเต็มต้องเป็นคู่หรือคี่อย่างใดอย่างหนึ่ง)

ความเชื่อมโยงกับความสัมพันธ์คอนกรูเอนซ์ $a \equiv b \pmod m$
Connection to Modulo Arithmetic

ความสัมพันธ์ $a + b$ เป็นเลขคู่ แท้จริงแล้วสมมูลกับ คอนกรูเอนซ์มอดุโล 2 ($a \equiv b \pmod 2$):

$$a + b \text{ เป็นเลขคู่} \iff a \text{ และ } b \text{ เป็นคู่ทั้งคู่ หรือเป็นคี่ทั้งคู่} \iff a \equiv b \pmod 2$$

สำหรับการพิสูจน์ทั่วไปของ $a \equiv b \pmod m$ (เมื่อ $m \in \mathbb{Z}^+$):

  • สะท้อน: $a - a = 0 = 0 \cdot m \implies m \mid (a - a) \implies a \equiv a \pmod m$
  • สมมาตร: $a - b = km \implies b - a = -(a - b) = (-k)m$ เนื่องจาก $-k \in \mathbb{Z} \implies b \equiv a \pmod m$
  • ถ่ายทอด: $(a - b) + (b - c) = k_1 m + k_2 m \implies a - c = (k_1 + k_2)m \implies a \equiv c \pmod m$
