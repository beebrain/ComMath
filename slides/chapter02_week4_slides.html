นิยามพื้นฐาน: เซต สมาชิก และวิธีเขียนเซตSets, Elements & Notation

นิยาม

เซตและสมาชิก ∈ / ∉

นิยาม เซต (Set) คือกลุ่มของวัตถุที่ระบุไว้อย่างชัดเจน เรียกวัตถุแต่ละชิ้นว่า สมาชิก (Element)
a ∈ A อ่านว่า "a เป็นสมาชิกของ A" · a ∉ A อ่านว่า "a ไม่เป็นสมาชิกของ A"
ตัวอย่าง: ให้ A = {1, 2, 3, 4, 5}
  • 3 ∈ A T
  • 7 ∈ A F  (นั่นคือ 7 ∉ A)
เชื่อมบทที่ 1 ข้อความ a ∈ A ตัดสินจริง/เท็จได้เสมอ จึงเป็น ประพจน์ — เขียนเป็นกฎกีดกันกลางได้ว่า (a ∈ A) ∨ (a ∉ A)

เซตมาตรฐาน

เซตของจำนวนที่ต้องรู้จัก ℕ ⊆ ℤ ⊆ ℚ ⊆ ℝ

  • ℕ = {0, 1, 2, 3, …} — จำนวนนับ (ตำราเล่มนี้เริ่มที่ 0)
  • ℤ = {…, −2, −1, 0, 1, 2, …} — จำนวนเต็ม (จากภาษาเยอรมัน Zahlen)
  • ℚ = {a/b | a, b ∈ ℤ, b ≠ 0} — จำนวนตรรกยะ (จาก Quotient)
  • ℝ — จำนวนจริง รวมจำนวนอตรรกยะ เช่น √2, π, e
ห่วงซ้อนกัน: ℕ ⊆ ℤ ⊆ ℚ ⊆ ℝ

วิธีเขียนเซตแบบที่ 2: บอกเงื่อนไข Set-builder Notation

แบบบอกเงื่อนไข เขียนในรูป {x | เงื่อนไขที่ x ต้องเป็นจริง} อ่านว่า "เซตของ x โดยที่ …" เหมาะกับเซตที่มีสมาชิกมากหรือเป็นอนันต์
  • {x ∈ ℤ | x > 0} = จำนวนเต็มบวก (ℤ+)
  • {x ∈ ℤ | x หารด้วย 2 ลงตัว} = จำนวนคู่
  • {x ∈ ℝ | x² − 5x + 6 = 0} = {2, 3} = เซตคำตอบของสมการ
เทียบโค้ด คล้าย list comprehension ของ Python: {x for x in range(100) if x % 2 == 0} ≈ {x ∈ ℕ | x < 100, x เป็นจำนวนคู่}

เซตย่อย Subset (⊆)

นิยาม A เป็น เซตย่อย ของ B เขียน A ⊆ B ก็ต่อเมื่อ ทุกสมาชิกของ A เป็นสมาชิกของ B ด้วย — เขียนด้วยตัวบ่งปริมาณ: ∀x (x ∈ A → x ∈ B)
  • {1, 2} ⊆ {1, 2, 3} T
  • {1, 2} ⊆ {2, 3} F (เพราะ 1 ∉ {2,3})
  • ∅ ⊆ {1, 2} T · A ⊆ A เสมอ T
วิธีพิสูจน์ จะพิสูจน์ A ⊆ B: สมมติ x ∈ A แล้วแสดงว่า x ∈ B (direct proof)
A ⊆ B — A อยู่ข้างใน B ทั้งก้อน

เซตย่อยแท้และความเท่ากัน

เซตย่อยแท้ และความเท่ากันของเซต

เซตย่อยแท้ A ⊊ B ก็ต่อเมื่อ A ⊆ B และ A ≠ B ("เป็นเซตย่อยแต่เล็กกว่าจริง ๆ") เช่น {1, 2} ⊊ {1, 2, 3}
หลักความเท่ากันของเซต A = B ⟺ A ⊆ B และ B ⊆ A
เทคนิคพิสูจน์มาตรฐาน Double inclusion: จะพิสูจน์เซตสองเซตเท่ากัน ให้พิสูจน์การเป็นเซตย่อย สองทิศทาง
(1) ทุก x ∈ A ⇒ x ∈ B    (2) ทุก x ∈ B ⇒ x ∈ A — เทคนิคนี้จะใช้หนักมากในสัปดาห์ที่ 5!

เรื่องเล่า · Bertrand Russell, 1901 ช่างตัดผมประจำหมู่บ้านประกาศว่า "ผมจะโกนหนวดให้ เฉพาะ คนที่ไม่โกนหนวดตัวเอง"
คำถาม: แล้วใครโกนหนวดให้ช่างตัดผม?
  • ถ้าช่างโกนให้ตัวเอง → ผิดประกาศ (เขาโกนให้เฉพาะคนที่ ไม่ โกนเอง)
  • ถ้าช่างไม่โกนให้ตัวเอง → ต้องโกนให้ตัวเอง (ตามประกาศ) — ขัดแย้งทั้งสองทาง!
  • ภาษาเซต: R = {x | x ∉ x} แล้วถามว่า R ∈ R หรือไม่ — Russell's Paradox
บทเรียน "กลุ่มของอะไรก็ได้" ไม่เป็นเซตเสมอไป — จึงต้องมี เอกภพสัมพัทธ์ U คอยกำกับขอบเขต

สรุปสัปดาห์ที่ 4

  • เซต = กลุ่มของสมาชิกที่ระบุชัดเจน ใช้ ∈ / ∉ บอกการเป็นสมาชิก
  • เขียนเซตได้ 2 แบบ: แจกแจงสมาชิก {1,2,3} และบอกเงื่อนไข {x | …}
  • กติกาเซต: ไม่มีลำดับ ไม่มีสมาชิกซ้ำ · เซตพิเศษ: ∅, U และ ∅ ≠ {∅}
  • เซตย่อย A ⊆ B: ทุกสมาชิกของ A อยู่ใน B · A = B ⟺ ⊆ ทั้งสองทาง
  • ∈ (สมาชิก–เซต) ไม่เหมือน ⊆ (เซต–เซต) — จุดออกข้อสอบยอดฮิต
สัปดาห์ถัดไป สัปดาห์ถัดไป: การดำเนินการระหว่างเซต (∪ ∩ − c) แผนภาพเวนน์ และกฎเดอมอร์แกน
