\vspace{0.3em}
\noindent วัตถุประสงค์การเรียนรู้ประจำบท\\[0.3em]
\noindent เมื่อนักศึกษาเรียนบทนี้จบแล้ว นักศึกษาจะสามารถ
\begin{enumerate}[topsep=0.3em, itemsep=0.25em]
    \item อธิบายสัจพจน์และกฎของพีชคณิตบูลีนได้
    \item ลดรูปสมการบูลีนโดยใช้กฎพีชคณิตบูลีนได้
    \item สร้างและวิเคราะห์วงจรประตูตรรกะจากนิพจน์บูลีนได้
    \item ใช้แผนที่การ์โนในการลดรูปฟังก์ชันบูลีนได้
    \item อธิบายรูปแบบปกติของฟังก์ชันบูลีนและประยุกต์ใช้ในการออกแบบวงจรดิจิทัลได้
    \item ออกแบบวงจรเชิงผสม วงจรบวก มัลติเพล็กเซอร์ และวงจรสถานะจำกัดเบื้องต้นได้
\end{enumerate}

\vspace{0.3em}
\noindent หัวข้อที่สอน\\[0.3em]
\begin{enumerate}[topsep=0.3em, itemsep=0.25em]
    \item สัจพจน์และกฎของพีชคณิตบูลีน
    \item นิพจน์และฟังก์ชันบูลีน
    \item รูปแบบปกติ SOP และ POS
    \item การลดรูปนิพจน์บูลีน
    \item วงจรประตูตรรกะ
    \item แผนที่การ์โน
    \item วงจรเชิงผสม วงจรบวก และวงจรสองระดับ
    \item มัลติเพล็กเซอร์ ดีมัลติเพล็กเซอร์ และวงจรสถานะจำกัด
\end{enumerate}

\vspace{1em}
\noindent สื่อการสอน
\begin{enumerate}[topsep=0.3em, itemsep=0.25em]
    \item สไลด์ประกอบการสอน
    \item แผนภาพวงจรและตัวอย่างการออกแบบวงจรลอจิก
    \item แบบฝึกหัดท้ายบท
\end{enumerate}
