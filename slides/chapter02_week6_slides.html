เพาเวอร์เซตPower Set

Definition

เพาเวอร์เซต: เซตของเซตย่อยทั้งหมด

นิยาม เพาเวอร์เซต ของ A เขียน 𝒫(A) คือเซตที่มีสมาชิกเป็น เซตย่อยทุกตัว ของ A: 𝒫(A) = {B | B ⊆ A}
ตัวอย่าง: A = {1, 2}
𝒫(A) = { ∅, {1}, {2}, {1,2} }
  • สมาชิกของ 𝒫(A) เป็น เซต ทุกตัว — เพาเวอร์เซตคือ "เซตของเซต"
  • ∅ ∈ 𝒫(A) และ A ∈ 𝒫(A) เสมอ (เซตย่อยเล็กสุดและใหญ่สุด)
ระวัง 𝒫(∅) = {∅} — ไม่ใช่ เซตว่าง! มันมีสมาชิก 1 ตัวคือ ∅

ผลคูณคาร์ทีเซียนCartesian Product

Definition

คู่อันดับ และผลคูณคาร์ทีเซียน

นิยาม คู่อันดับ (Ordered Pair) (a, b) — ลำดับสำคัญ: (a,b) ≠ (b,a) ยกเว้น a = b
ผลคูณคาร์ทีเซียน: A × B = {(a, b) | a ∈ A และ b ∈ B}
ตัวอย่าง: A = {1, 2}, B = {a, b}
A × B = {(1,a), (1,b), (2,a), (2,b)}
  • เทียบกับเซต: {a, b} = {b, a} แต่ (a, b) ≠ (b, a) — ความต่างสำคัญ!
  • A × B ≠ B × A โดยทั่วไป (ไม่มีสมบัติสลับที่) · ∅ × A = ∅
  • ตั้งชื่อตาม René Descartes — ℝ × ℝ = ℝ² คือระนาบพิกัดที่เราใช้ทุกวัน

การนับจำนวนสมาชิก และหลักการรวม-การแยกCardinality & Inclusion–Exclusion

Definition

คาร์ดินัลลิตี้ (Cardinality) และสูตรนับที่มีแล้ว

นิยาม คาร์ดินัลลิตี้ ของเซต A เขียน |A| = จำนวนสมาชิกของ A เช่น |{a, b, c}| = 3, |∅| = 0
สูตรนับที่ได้มาแล้ววันนี้
  • เพาเวอร์เซต: |𝒫(A)| = 2|A|
  • ผลคูณคาร์ทีเซียน: |A × B| = |A| · |B|
คำถามถัดไป แล้ว |A ∪ B| ล่ะ? บวกกันตรง ๆ ได้ไหม?

Inclusion–Exclusion

หลักการรวม-การแยก

บวกตรง ๆ ไม่ได้! ถ้านับ |A| + |B| สมาชิกที่อยู่ ทั้งสองเซต จะถูกนับ ซ้ำสองครั้ง
สูตร |A ∪ B| = |A| + |B| − |A ∩ B|
  • A = {1,2,3,4}, B = {3,4,5,6}: 4 + 4 = 8 แต่ 3, 4 ถูกนับซ้ำ
  • |A ∪ B| = 4 + 4 − 2 = 6 ✓ ตรงกับ |{1,…,6}|
  • ถ้า A ∩ B = ∅ (แยกกัน): |A ∪ B| = |A| + |B| พอดี
ช่องกลาง (2 ตัว) อยู่ทั้ง A และ B — ต้องหักออกหนึ่งครั้ง

ตัวอย่าง: โจทย์นับนักศึกษา

โจทย์ นักศึกษา 80 คน เรียนคณิตศาสตร์ 50 คน เรียนคอมพิวเตอร์ 40 คน และเรียน ทั้งสองวิชา 20 คน
(ก) มีกี่คนที่เรียน อย่างน้อยหนึ่งวิชา?   (ข) มีกี่คนที่ ไม่เรียนสักวิชา?
ให้ M = เซตคนเรียนคณิต, C = เซตคนเรียนคอม, |U| = 80
(ก) |M ∪ C| = |M| + |C| − |M ∩ C| = 50 + 40 − 20 = 70 คน
(ข) |(M ∪ C)c| = |U| − |M ∪ C| = 80 − 70 = 10 คน

เกร็ดปิดท้าย: โรงแรมของฮิลเบิร์ต กับอนันต์หลายระดับ

Hilbert's Hotel โรงแรมมีห้อง 1, 2, 3, … ไม่สิ้นสุด และ เต็มทุกห้อง มีแขกใหม่มา 1 คน — รับได้ไหม?
ได้! ให้แขกห้อง n ย้ายไปห้อง n+1 ทุกคน แล้วห้อง 1 ก็ว่าง
  • เซตอนันต์จึง "แปลก": เพิ่มสมาชิกแล้วขนาดเท่าเดิม — เรียกว่า เซตนับได้ (Countable) เช่น ℕ, ℤ และแม้แต่ ℚ
  • แต่ Cantor พิสูจน์ (diagonal argument) ว่า ℝ นับไม่ได้ (Uncountable) — จับคู่กับห้องอย่างไรก็มีจำนวนจริง "ตกค้าง" เสมอ
  • สรุป: |ℕ| = |ℤ| = |ℚ| < |ℝ| — อนันต์มีหลายระดับจริง ๆ
ส่วนนี้เป็นความรู้รอบตัว (ไม่ออกสอบละเอียด) — อ่านเพิ่มในหัวข้อ "เซตนับได้และเซตนับไม่ได้" ของตำรา

  • เพาเวอร์เซต 𝒫(A) = เซตของเซตย่อยทั้งหมด · |𝒫(A)| = 2|A|
