Concept 1.1

นิยามฟังก์ชัน (Function Definition $f: A \to B$)

DEF นิยามฟังก์ชันเชิงเซต
ให้ $A$ และ $B$ เป็นเซต ฟังก์ชัน $f$ จาก $A$ ไปยัง $B$ เขียนแทนด้วย $f: A \to B$ คือความสัมพันธ์ $f \subseteq A \times B$ ซึ่ง: $$\mathbf{\forall x \in A, \exists! y \in B \text{ such that } (x, y) \in f \quad (y = f(x))}$$
2 RULES เงื่อนไขเหล็ก 2 ประการที่ต้องเป็นจริงพร้อมกัน
1. Total Mapping (จับคู่ครบ): สมาชิกตัวหน้า $x \in A$ ทุกตัว ต้องมีคู่ใน $B$ (ห้ามมีโหนดว่าง)
2. Uniqueness (ผลลัพธ์เดียว): สมาชิกตัวหน้าแต่ละตัวจับคู่กับตัวหลังได้ เพียงค่าเดียวเท่านั้น (ห้ามแตกกิ่ง)

Concept 1.2

ความสัมพันธ์ vs ฟังก์ชัน (Relation vs Function)

มิติการเปรียบเทียบ ความสัมพันธ์ (Relation $R$) ฟังก์ชัน (Function $f$)
นิยามเชิงเซต สับเซตใดๆ ของผลคูณคาร์ทีเซียน ($R \subseteq A \times B$) ความสัมพันธ์จำเพาะที่อินพุตแต่ละตัวมีเอาต์พุตเดียว
การใช้สมาชิกต้นทาง สมาชิก $x \in A$ ไม่จำเป็นต้องถูกใช้ทุกตัว สมาชิก $x \in A$ ทุกตัวต้องถูกจับคู่ ($\operatorname{Dom}(f) = A$)
จำนวนคู่ต่อหนึ่งอินพุต $x$ 1 ตัวจับคู่กับ $y$ ได้ 0, 1 หรือหลายตัว $x$ 1 ตัว ต้องจับคู่กับ $y$ ได้เพียง 1 ตัวพอดี
ความสัมพันธ์ระหว่างเซต ฟังก์ชันทุกตัวเป็นความสัมพันธ์ แต่ความสัมพันธ์ไม่ใช่ทุกตัวที่เป็นฟังก์ชัน ($f \subset R \subset A \times B$)

Concept 1.3

วิเคราะห์ 4 รูปแบบตัวอย่าง ($f_1$ ถึง $f_4$ จากใบกิจกรรมที่ 1)

กำหนด $A = \{1, 2, 3, 4\}$ และ $B = \{a, b, c, d\}$ ตรวจสอบความเป็นฟังก์ชันจาก $A$ ไป $B$:
✓ เป็นฟังก์ชัน $f_1 = \{(1, a), (2, b), (3, c), (4, d)\}$
สมาชิก $A$ ครบทุกตัว ($1, 2, 3, 4$) แต่ละตัวจับคู่ปลายทางตัวเดียวพอดี $\to$ เป็นฟังก์ชัน (และเป็น 1-1)
✓ เป็นฟังก์ชัน $f_2 = \{(1, a), (2, a), (3, b), (4, c)\}$
สมาชิก $1, 2, 3, 4$ มีคู่ครบ และส่งไปค่าเดียว (แม้ $1, 2$ จะส่งไป $a$ เหมือนกัน แต่ถือเป็น Many-to-One ยอมรับได้)
✗ ไม่เป็นฟังก์ชัน $f_3 = \{(1, a), (2, b), (2, c), (3, d), (4, a)\}$
ไม่เป็นฟังก์ชัน! เพราะสมาชิก $2 \in A$ จับคู่กับปลายทาง 2 ค่าพร้อมกัน ($b$ และ $c$) ฝ่าฝืน Uniqueness
✗ ไม่เป็นฟังก์ชัน $f_4 = \{(1, a), (3, b), (4, c)\}$
ไม่เป็นฟังก์ชันจาก A ไป B! เพราะสมาชิก $2 \in A$ ไม่ถูกจับคู่ ฝ่าฝืน Total Mapping ($\operatorname{Dom}(f_4) \neq A$)
4 กรณีตัวอย่างตรวจสอบฟังก์ชัน4091606 · CH03-W08
Concept 1.4

ฟังก์ชันในวิทยาการคอมพิวเตอร์และ Pure Function

CONCEPT Pure Function ใน Functional Programming
คือฟังก์ชันที่มีพฤติกรรมสอดคล้องกับคณิตศาสตร์ 100%:
  • Deterministic Output: ส่ง Input เดิม ย่อมได้ Output เดิมเสมอ
  • No Side Effects: ไม่แอบแก้ไขตัวแปร Global หรือ I/O นอกฟังก์ชัน
WHY ประโยชน์ในระบบขนาดใหญ่
ช่วยให้ทำ Memoization (แคชผลลัพธ์) ได้ปลอดภัย และประมวลผลแบบขนาน (Parallel / MapReduce) ได้โดยไม่เกิด Race Condition
# Pure Function (ทำนายผลได้ 100%) def add(a, b): return a + b # Impure Function (มี Side Effects) total = 0 def accumulate(x): global total total += x # แก้ไขตัวแปรภายนอก! return total

Concept 1.5

การตรวจสอบด้วยแผนภาพลูกศร (Arrow Diagram Rules)

✓ เกณฑ์ผ่าน ลูกศรพุ่งออกจากต้นทาง 1 เส้นพอดี
ทุกโหนดในเซตต้นทาง $A$ ต้องมีลูกศรพุ่งออก 1 เส้นพอดี

Concept 1.7

โดเมน (Domain) และโคโดเมน (Codomain)

DOMAIN โดเมน $\operatorname{Dom}(f)$
เซตของสมาชิกต้นทางทั้งหมด:
$$\mathbf{\operatorname{Dom}(f) = A}$$ • สำหรับฟังก์ชัน โดเมนต้องเท่ากับเซตต้นทาง $A$ เต็มทั้งเซตเสมอ
• ในการเขียนโปรแกรม เปรียบเสมือน Parameter Type เช่น x: int
CODOMAIN โคโดเมน (Codomain)
เซตปลายทางทั้งหมด $B$ ที่ระบุขอบเขตของประเภทผลลัพธ์:
• เป็นประเภทของข้อมูลที่อนุญาตให้คืนค่าออกมา
• ในการเขียนโปรแกรม เปรียบเสมือน Return Type เช่น float myFunc(int x) $\implies$ โคโดเมนคือเซตของ Float

Concept 1.8

เรนจ์ (Range) หรือภาพของฟังก์ชัน (Image $f(A)$)

DEF เรนจ์ $\operatorname{Ran}(f)$
เซตของค่าผลลัพธ์จริงที่ถูกจับคู่โดยฟังก์ชัน $f$: $$\mathbf{\operatorname{Ran}(f) = \{f(x) \mid x \in A\} \subseteq B}$$ • สมาชิกในโคโดเมน $B$ อาจมีสมาชิกบางตัวที่ไม่เคยถูกจับคู่เลย
EXAMPLE ตัวอย่างการแยกแยะ โคโดเมน vs เรนจ์
ให้ $f: \mathbb{R} \to \mathbb{R}$ โดย $f(x) = x^2$
• โดเมน: $\mathbb{R}$ (จำนวนจริงทั้งหมด)
• โคโดเมน: $\mathbb{R}$ (ระบุไว้ว่าผลลัพธ์เป็นจำนวนจริงใดๆ)
• เรนจ์: $[0, \infty)$ (เพราะเลขยกกำลังสองไม่มีทางติดลบ!) $\implies \mathbf{\operatorname{Ran}(f) \subsetneq \text{Codomain}}$

Concept 1.9

ตัวอย่างเชิงลึก: หาโดเมนและเรนจ์ของ $g(x) = x^2 - 4x + 7$

STEP 1 โดเมนของฟังก์ชัน
เนื่องจาก $g(x) = x^2 - 4x + 7$ เป็นพหุนาม ไม่มีตัวส่วนเป็นศูนย์และไม่มีค่าติดลบใต้กรณฑ์รากที่สอง
ดังนั้น สามารถคำนวณหาค่าได้สำหรับทุกจำนวนจริง $\implies \mathbf{\operatorname{Dom}(g) = \mathbb{R}}$
STEP 2 เรนจ์ด้วยการจัดรูปกำลังสองสมบูรณ์ (Completing the Square)
$$g(x) = x^2 - 4x + 7 = (x^2 - 4x + 4) + 3 = \mathbf{(x - 2)^2 + 3}$$ เนื่องจาก $(x - 2)^2 \ge 0$ สำหรับทุก $x \in \mathbb{R}$ เสมอ
ดังนั้น $g(x) \ge 0 + 3 = 3$ โดยมีจุดต่ำสุดอยู่ที่ $g(2) = 3$
สรุปได้ว่า เรนจ์ของฟังก์ชันคือ: $\mathbf{\operatorname{Ran}(g) = [3, \infty) = \{y \in \mathbb{R} \mid y \ge 3\}}$

Concept 2.1

ฟังก์ชันหนึ่งต่อหนึ่ง (Injective / One-to-One)

DEF นิยามฟังก์ชันหนึ่งต่อหนึ่ง
สมาชิกปลายทางแต่ละตัวโดนจับคู่ ไม่เกิน 1 ครั้ง (ไม่มีลูกศรชนกัน): $$\mathbf{\forall a, b \in A, f(a) = f(b) \implies a = b}$$ หรือเขียนในรูปประพจน์แย้งสลับที่ (Contrapositive) ที่เข้าใจง่าย: $$\mathbf{\forall a, b \in A, a \neq b \implies f(a) \neq f(b)}$$ "อินพุตต่างกัน ต้องได้ผลลัพธ์ต่างกันเสมอ"
ฟังก์ชันหนึ่งต่อหนึ่ง4091606 · CH03-W08
Concept 2.2

การตรวจสอบ Injective ทางพีชคณิต (Algebraic Verification)

✓ ตัวอย่าง 1 $f(x) = 3x - 5$ บน $\mathbb{R} \to \mathbb{R}$
สมมุติให้ $f(a) = f(b)$:
$$3a - 5 = 3b - 5$$ $$3a = 3b \implies \mathbf{a = b}$$ สรุปได้ทันทีว่า f เป็นฟังก์ชันหนึ่งต่อหนึ่ง (Injective)
✗ ตัวอย่าง 2 $g(x) = x^2$ บน $\mathbb{R} \to \mathbb{R}$
สมมุติให้ $g(a) = g(b)$:
$$a^2 = b^2 \implies \mathbf{a = \pm b}$$ เช่น เลือก $a = 2$ และ $b = -2$ ($a \neq b$)
แต่ $g(2) = 4$ และ $g(-2) = 4$ (ได้ผลลัพธ์ชนกัน!)
สรุปได้ว่า g ไม่เป็นฟังก์ชันหนึ่งต่อหนึ่ง

Concept 2.3

การทดสอบเส้นแนวนอน (Horizontal Line Test)

TEST กฎเส้นแนวนอนบนกราฟ
ฟังก์ชันจะเป็นหนึ่งต่อหนึ่ง ก็ต่อเมื่อ ไม่มีเส้นตรงแนวนอนใดๆ ($y = k$) ลากตัดกราฟเกินกว่า 1 จุด
NOTE ข้อแตกต่าง
• เส้นแนวตั้ง (Vertical): ตรวจสอบว่า "เป็นฟังก์ชันหรือไม่"
• เส้นแนวนอน (Horizontal): ตรวจสอบว่า "เป็นหนึ่งต่อหนึ่งหรือไม่"
EX การเปรียบเทียบ
• $f(x) = 2x + 1$ $\implies$ เส้นแนวนอนตัด 1 จุดเสมอ $\to$ ✓ เป็น Injective

• $f(x) = x^2$ $\implies$ เส้นแนวนอน $y = 4$ ตัดกราฟ 2 จุด ($x = 2, -2$) $\to$ ✗ ไม่เป็น Injective

Concept 2.4

ฟังก์ชันทั่วถึง (Surjective / Onto)

DEF นิยามฟังก์ชันทั่วถึง
สมาชิกในโคโดเมน $B$ ทุกตัวต้องถูกจับคู่อย่างน้อย 1 ครั้ง (ไม่มีตัวใดใน $B$ ถูกทิ้งว่าง): $$\mathbf{\forall y \in B, \exists x \in A \text{ such that } f(x) = y}$$
CRITERIA เกณฑ์ตรวจสอบที่ง่ายและแม่นยำที่สุด
ฟังก์ชัน $f: A \to B$ จะเป็นฟังก์ชันทั่วถึง ก็ต่อเมื่อ เรนจ์เท่ากับโคโดเมนพอดี: $$\mathbf{\operatorname{Ran}(f) = B}$$

Concept 2.5

การตรวจสอบ Surjective ทางพีชคณิต (Algebraic Verification)

ALGORITHM กระบวนการตรวจสอบทางพีชคณิต
1. กำหนดให้ $y \in B$ เป็นสมาชิกใดๆ ในโคโดเมน
2. ตั้งสมการ $y = f(x)$ แล้วจัดรูป แก้สมการหา $x$ ในรูปของ $y$ ($x = \dots$)
3. ตรวจสอบว่า ค่า $x$ ที่ได้นั้น ตกอยู่ในโดเมน $A$ เสมอหรือไม่
EXAMPLE ให้ $f: \mathbb{R} \to \mathbb{R}$ โดย $f(x) = 3x - 5$

Concept 2.6

อิทธิพลของชนิดข้อมูล: $f(x) = 2x$ บน $\mathbb{R}$ vs $\mathbb{Z}$

✓ ทั่วถึง $f: \mathbb{R} \to \mathbb{R}$ โดย $f(x) = 2x$
• ให้ $y \in \mathbb{R}$ จะได้ $x = y/2$
• จำนวนจริงหาร 2 ยังคงเป็นจำนวนจริงเสมอ ($x \in \mathbb{R}$)
• $\operatorname{Ran}(f) = \mathbb{R} = \text{Codomain}$ $\to$ เป็นทั่วถึง (Surjective)
✗ ไม่ทั่วถึง! $g: \mathbb{Z} \to \mathbb{Z}$ โดย $g(x) = 2x$
• ให้ $y \in \mathbb{Z}$ จะได้ $x = y/2$
• ถ้าเลือกจำนวนคี่ เช่น $y = 3 \in \mathbb{Z}$ จะได้ $x = 1.5 \notin \mathbb{Z}$
• เรนจ์มีเฉพาะจำนวนคู่ $\{\dots, -2, 0, 2, 4, \dots\} \neq \mathbb{Z}$ $\to$ ไม่เป็นทั่วถึง!
บทเรียนสำคัญ: ฟังก์ชันสูตรเดียวกัน เมื่อเปลี่ยนประเภทข้อมูลของโดเมน/โคโดเมน สมบัติทางคณิตศาสตร์เปลี่ยนไปทันที!

Concept 2.7

ฟังก์ชันหนึ่งต่อหนึ่งทั่วถึง (Bijective Function)

DEF นิยาม Bijective (One-to-One Correspondence)
ฟังก์ชันที่เป็น ทั้งหนึ่งต่อหนึ่ง (Injective) และทั่วถึง (Surjective) พร้อมกัน: $$\mathbf{\text{Bijective} = \text{Injective} \land \text{Surjective}}$$
PROPERTY สมบัติการมีฟังก์ชันผกผัน

  • ถ้าไม่ทั่วถึง $\implies$ ย้อนกลับแล้วมีบาง $y$ ที่ไม่มีลูกศรออก (โดเมนไม่ครบ)

Concept 2.8

เมทริกซ์ 4 รูปแบบการจับคู่ของฟังก์ชัน (The 4-Quadrant Matrix)

ประเภท สมบัติทางเซต & แผนภาพลูกศร ตัวอย่างทางคณิตศาสตร์ ($A \to B$)
1. Injective Only ลูกศรไม่ชนกัน แต่ปลายทางมีโหนดเหลือว่าง ($|A| \le |B|$) $f: \mathbb{N} \to \mathbb{R}$ โดย $f(x) = x$
2. Surjective Only ปลายทางถูกใช้ครบทุกโหนด แต่มีลูกศรชนกัน ($|A| \ge |B|$) $f: \mathbb{R} \to [0, \infty)$ โดย $f(x) = x^2$
3. Bijective จับคู่สมบูรณ์แบบ 1 ต่อ 1 ครบทุกคู่ ($|A| = |B|$) มี $f^{-1}$ $f: \mathbb{R} \to \mathbb{R}$ โดย $f(x) = 3x - 5$
4. Neither ทั้งมีลูกศรชนกัน และมีโหนดปลายทางเหลือว่าง $f: \mathbb{R} \to \mathbb{R}$ โดย $f(x) = x^2$

Concept 3.3

ตัวอย่างการคำนวณและสมบัติไม่สลับที่ (Non-commutative)

EXAMPLE ให้ $f(x) = 2x + 3$ และ $g(x) = x^2 - 1$
1. หา $(f \circ g)(x)$ :
$$(f \circ g)(x) = f(g(x)) = f(x^2 - 1) = 2(x^2 - 1) + 3 = \mathbf{2x^2 + 1}$$ 2. หา $(g \circ f)(x)$ :
$$(g \circ f)(x) = g(f(x)) = g(2x + 3) = (2x + 3)^2 - 1 = (4x^2 + 12x + 9) - 1 = \mathbf{4x^2 + 12x + 8}$$
CAUTION ข้อควรระวังสูงสุด
$(f \circ g)(x) \neq (g \circ f)(x)$ — การประกอบฟังก์ชัน ไม่มีสมบัติการสลับที่ (Non-commutative)

DEF นิยามฟังก์ชันผกผัน

Concept 3.7

ตัวอย่างเชิงลึก: ฟังก์ชันตรรกยะและสมมาตร $y = x$

EXAMPLE จงหา $f^{-1}(x)$ ของ $f(x) = \frac{2x + 1}{x - 3}$ ($x \neq 3$)
1. $y = \frac{2x + 1}{x - 3} \implies y(x - 3) = 2x + 1$
2. $yx - 3y = 2x + 1 \implies yx - 2x = 3y + 1$
3. $x(y - 2) = 3y + 1 \implies x = \frac{3y + 1}{y - 2}$
$\therefore \mathbf{f^{-1}(x) = \frac{3x + 1}{x - 2}} \quad (x \neq 2)$
SYMMETRY สมมาตรทางเรขาคณิต
กราฟของฟังก์ชัน $f(x)$ และกราฟของฟังก์ชันผกผัน $f^{-1}(x)$ จะเป็น ภาพสะท้อน (Reflection) ซึ่งกันและกัน ข้ามเส้นตรง $y = x$ เสมอ!

ถ้า $(a, b)$ อยู่บนกราฟ $f$ แล้ว $(b, a)$ จะต้องอยู่บนกราฟ $f^{-1}$ เสมอ

การประยุกต์: การแบ่งหน้าข้อมูล (Pagination Formula)

FORMULA สูตรคำนวณจำนวนหน้าเว็บ
เมื่อมีข้อมูลทั้งหมด $N$ รายการ และต้องการแสดงผลหน้าละ $S$ รายการ: $$\mathbf{\text{จำนวนหน้าทั้งหมด} = \lceil N / S \rceil}$$
EX กรณีศึกษาจากใบกิจกรรม

$$\text{จำนวนหน้า} = \lceil 155 / 20 \rceil = \lceil 7.75 \rceil = \mathbf{8 \text{ หน้า}}$$

การเลื่อนตำแหน่งดัชนีใน Circular Buffer หรือ Round-Robin Scheduling บนอาร์เรย์ขนาด $N$: $$\mathbf{\text{next\_index} = (\text{current\_index} + 1) \bmod N}$$
EX ตัวอย่าง
อาร์เรย์ขนาด $N = 5$ (ดัชนี $0, 1, 2, 3, 4$):
เมื่ออยู่ที่ดัชนี $4 \implies (4 + 1) \bmod 5 = 5 \bmod 5 = \mathbf{0}$ (วนกลับมาหัวแถวอัตโนมัติ โดยไม่ต้องเขียน if-else เช็ค)

Concept 4.7

ฟังก์ชันแฮช (Hash Function $h(k) = k \bmod m$)

DEF นิยามฟังก์ชันแฮช
ฟังก์ชันที่แปลงคีย์ข้อมูลขนาดใหญ่ $k$ ให้เป็นดัชนีช่องตารางขนาดจำกัด $m$: $$\mathbf{h(k) = k \bmod m}$$ ช่วยให้ระบบสามารถค้นหา (Search), แทรก (Insert), และลบ (Delete) ข้อมูลได้ด้วยความเร็วเฉลี่ยระดับ $O(1)$
EX ตัวอย่าง (ตารางขนาด $m = 7$ ช่อง $0$ ถึง $6$)
• $h(24) = 24 \bmod 7 = \mathbf{3}$
• $h(15) = 15 \bmod 7 = \mathbf{1}$
• $h(62) = 62 \bmod 7 = \mathbf{6}$

Concept 4.8

การชนกันของแฮช (Hash Collision) และวิธีรับมือ

PROBLEM นิยามการชนกัน
เกิดขึ้นเมื่อคีย์ข้อมูลที่ต่างกัน ($k_1 \neq k_2$) ถูกแปลงแล้วได้ดัชนีช่องเดียวกัน: $h(k_1) = h(k_2)$
สำหรับ $h(k) = k \bmod 7$: $h(15) = 1$ และ $h(50) = 50 \bmod 7 = 1$ (เกิดการชนกันที่ช่องดัชนี 1!)
1 Separate Chaining
แต่ละช่องตารางเก็บเป็น Linked List เมื่อมีคีย์ชนกัน ให้นำโหนดใหม่ไปต่อท้ายสายโซ่
2 Open Addressing (Linear Probing)
ถ้าช่องดัชนีนั้นเต็ม ให้เลื่อนไปดูช่องถัดไปทีละ 1: $h(k, i) = (h(k) + i) \bmod m$

Concept 4.9

โครงสร้างของฟังก์ชันแบบเรียกซ้ำ (Recursive Functions)

1 กรณีฐาน (Base Case)
เงื่อนไขหยุดที่คืนค่าผลลัพธ์ทันทีโดยไม่เรียกซ้ำอีก เพื่อป้องกันการวนรอบไม่รู้จบ
2 ขั้นตอนเรียกซ้ำ (Recursive Step)
การเรียกฟังก์ชันตัวเองซ้ำโดยลดขนาดของปัญหาลงทีละขั้นเข้าสู่กรณีฐาน
FORMULA ฟังก์ชันแฟกทอเรียล $f(n)$
$$f(n) = \begin{cases} 1 & n = 0 \text{ (กรณีฐาน)}\\ n \cdot f(n-1) & n \ge 1 \text{ (ขั้นตอนเรียกซ้ำ)} \end{cases}$$

Concept 4.10

การทำงานบนหน่วยความจำ (Call Stack) และ Memoization

STACK TRACE การคำนวณ $3!$ ($f(3)$)
$f(3) \to 3 \cdot f(2)$
$\quad \to 2 \cdot f(1)$
$\quad\quad \to 1 \cdot f(0) \implies \text{Base Hit: คืนค่า } 1$
$\quad \leftarrow 2 \cdot 1 = 2$
$\leftarrow 3 \cdot 2 = \mathbf{6}$
OVERFLOW ข้อควรระวัง
หากไม่มี Base Case ฟังก์ชันจะกินพื้นที่ Stack จนเต็มและเกิดข้อผิดพลาด Stack Overflow!
OPTIMIZE เทคนิค Memoization
ฟังก์ชันเช่น Fibonacci คำนวณซ้ำซ้อนระดับ $O(2^n)$ หากนำผลลัพธ์มาจำไว้ในตาราง (Cache) จะลดเหลือเพียง $O(n)$
