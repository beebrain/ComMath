Concept 1.1

นิยามฟังก์ชัน (Function Definition $f: A \to B$)

DEF นิยามฟังก์ชัน
ความสัมพันธ์ $f$ จากเซต $A$ ไปยังเซต $B$ จะเป็น ฟังก์ชัน ก็ต่อเมื่อ: $$\mathbf{\forall x \in A, \exists! y \in B \text{ such that } (x, y) \in f}$$ สมาชิกตัวหน้า $x \in A$ ทุกตัวต้องถูกจับคู่ และจับคู่กับตัวหลัง $y \in B$ ได้ เพียงตัวเดียวเท่านั้น (Uniqueness)
PURE FUNCTION ความหมายในเชิงคอมพิวเตอร์
การป้อน Input เดิม จะต้องให้ผลลัพธ์ Output ค่าเดิมที่แน่นอนเพียงค่าเดียวเสมอ (Deterministic)
นิยามฟังก์ชัน4091606 · CH03-W08
Concept 1.2

การทดสอบเส้นแนวตั้ง (Vertical Line Test)

TEST กฎการทดสอบ
กราฟบนระนาบพิกัดฉากจะเป็นฟังก์ชัน ก็ต่อเมื่อ ไม่มีเส้นตรงแนวตั้งใดๆ ตัดกราฟเกินกว่า 1 จุด
EX ตัวอย่าง
• $y = x^2$ $\implies$ เส้นแนวตั้งตัด 1 จุดเสมอ $\to$ ✓ เป็นฟังก์ชัน
• $x^2 + y^2 = 1$ (วงกลม) $\implies$ เส้นแนวตั้งตัด 2 จุด $\to$ ✗ ไม่เป็นฟังก์ชัน
Vertical Line Test4091606 · CH03-W08
Concept 1.3

โดเมน โคโดเมน (Codomain) และเรนจ์ของฟังก์ชัน

1 โดเมน $\operatorname{Dom}(f)$
เซตต้นทางทั้งหมด:
$$\mathbf{\operatorname{Dom}(f) = A}$$
2 โคโดเมน (Codomain)
เซตปลายทางทั้งหมด $B$ ที่ระบุชนิดข้อมูล (Type Specification)
3 เรนจ์ $\operatorname{Ran}(f)$
เซตของผลลัพธ์จริงที่ถูกจับคู่:
$$\mathbf{\operatorname{Ran}(f) \subseteq B}$$
CAUTION ตัวอย่างที่โคโดเมน $\neq$ เรนจ์
$f: \mathbb{R} \to \mathbb{R}$ โดย $f(x) = x^2 \implies$ โคโดเมนคือ $\mathbb{R}$ แต่เรนจ์คือเฉพาะ $[0, \infty)$

การจำแนกประเภทของฟังก์ชันInjective, Surjective & Bijective Functions

Concept 2.1

ฟังก์ชันหนึ่งต่อหนึ่ง (Injective / One-to-One)

DEF นิยามฟังก์ชันหนึ่งต่อหนึ่ง
สมาชิกปลายทางแต่ละตัวโดนจับคู่ ไม่เกิน 1 ครั้ง (ห้ามมีลูกศรชนกัน): $$\mathbf{\forall a, b \in A, f(a) = f(b) \implies a = b}$$
✓ เป็นหนึ่งต่อหนึ่ง
$f(x) = 2x + 1$ บน $\mathbb{R}$
ถ้า $2a + 1 = 2b + 1 \implies 2a = 2b \implies a = b$
✗ ไม่เป็นหนึ่งต่อหนึ่ง
$f(x) = x^2$ บน $\mathbb{R}$
$f(2) = 4$ และ $f(-2) = 4$ มีผลลัพธ์ชนกันที่ 4
ฟังก์ชันหนึ่งต่อหนึ่ง4091606 · CH03-W08
Concept 2.2

ฟังก์ชันทั่วถึง (Surjective / Onto)

DEF นิยามฟังก์ชันทั่วถึง
สมาชิกในโคโดเมน $B$ ทุกตัวต้องถูกจับคู่อย่างน้อย 1 ครั้ง (ไม่มีตัวใดถูกทิ้งว่าง): $$\mathbf{\forall y \in B, \exists x \in A \text{ such that } f(x) = y \iff \operatorname{Ran}(f) = B}$$
✓ เป็นทั่วถึง
$f: \mathbb{R} \to \mathbb{R}$ โดย $f(x) = 3x - 5$
สำหรับ $y \in \mathbb{R}$ จะมี $x = \frac{y+5}{3} \in \mathbb{R}$ เสมอ
✗ ไม่เป็นทั่วถึง
$f: \mathbb{Z} \to \mathbb{Z}$ โดย $f(x) = 2x$
เรนจ์มีเฉพาะเลขคู่ จำนวนเต็มคี่เช่น 3 ไม่มี $x$ ที่ $2x = 3$
ฟังก์ชันทั่วถึง4091606 · CH03-W08
Concept 2.3

ฟังก์ชันหนึ่งต่อหนึ่งทั่วถึง (Bijective Function)

DEF นิยามฟังก์ชันแบบ Bijection
ฟังก์ชันที่เป็น ทั้งหนึ่งต่อหนึ่ง และทั่วถึงพร้อมกัน: $$\mathbf{\text{Bijective} = \text{Injective} \land \text{Surjective}}$$
THEOREM ทฤษฎีบทการมีฟังก์ชันผกผัน
ฟังก์ชัน $f: A \to B$ จะมี ฟังก์ชันผกผัน $f^{-1}: B \to A$ ได้ ก็ต่อเมื่อ $f$ เป็น Bijective เท่านั้น!
ฟังก์ชันหนึ่งต่อหนึ่งทั่วถึง4091606 · CH03-W08
Concept 2.4

หลักการช่องนกพิราบ (Pigeonhole Principle)

THEOREM หลักการช่องนกพิราบ
ถ้านำนกพิราบ $k + 1$ ตัว ใส่ในรังนก $k$ รัง จะมีรังนกอย่างน้อย 1 รังที่มีนกตั้งแต่ 2 ตัวขึ้นไป
• ในมุมมองของฟังก์ชัน $f: A \to B$: ถ้า $|A| > |B|$ แล้ว $f$ ไม่มีทางเป็น Injective ได้เลย!
HASH การชนกันของแฮช (Collision)
คีย์ $N = 10,000$ ตัว ใส่ตารางขนาด $M = 1,000$ ช่อง ย่อมเกิดการชนกันแน่นอน
COMPRESS การบีบอัดไฟล์
ไม่มีอัลกอริทึมใดบีบอัดไฟล์ทุกขนาดให้เล็กลงได้เสมอโดยไม่สูญเสียข้อมูล

การประกอบฟังก์ชันและฟังก์ชันผกผันFunction Composition & Inverses

Concept 3.1

การประกอบฟังก์ชัน (Function Composition $f \circ g$)

DEF นิยามฟังก์ชันประกอบ
ให้ $g: A \to B$ และ $f: B \to C$ ฟังก์ชันประกอบ $f \circ g: A \to C$ คือ: $$\mathbf{(f \circ g)(x) = f(g(x))}$$ • นำค่า $x$ ป้อนให้ $g$ ก่อน เมื่อได้ผลลัพธ์ $g(x)$ ให้นำไปป้อนต่อให้ $f$
EXAMPLE ตัวอย่างคำนวณ
ให้ $f(x) = 2x + 3$ และ $g(x) = x^2 - 1$
$$\mathbf{(f \circ g)(x) = f(x^2 - 1) = 2(x^2 - 1) + 3 = 2x^2 + 1}$$ $$\mathbf{(g \circ f)(x) = g(2x + 3) = (2x + 3)^2 - 1 = 4x^2 + 12x + 8}$$ ข้อสังเกต: โดยทั่วไป $(f \circ g)(x) \neq (g \circ f)(x)$ (ไม่มีสมบัติสลับที่)
การประกอบฟังก์ชัน4091606 · CH03-W08
Concept 3.2

ฟังก์ชันผกผัน (Inverse Function $f^{-1}$)

DEF นิยามฟังก์ชันผกผัน
ถ้า $f: A \to B$ เป็น Bijective จะมีฟังก์ชันผกผัน $f^{-1}: B \to A$ ซึ่ง: $$\mathbf{f^{-1}(y) = x \iff f(x) = y}$$ $$\mathbf{(f^{-1} \circ f)(x) = x \quad \text{และ} \quad (f \circ f^{-1})(y) = y}$$
PROCEDURE ขั้นตอนการหา $f^{-1}(x)$
1. ตั้งสมการ $y = f(x)$ เช่น $y = 3x - 5$
2. จัดรูปสมการแก้หาตัวแปร $x$ ในเทอมของ $y$: $3x = y + 5 \implies x = \frac{y + 5}{3}$
3. สลับตัวแปร $y$ กลับเป็น $x$: $\mathbf{f^{-1}(x) = \frac{x + 5}{3}}$

ฟังก์ชันพิเศษทางคอมพิวเตอร์Special Functions: Floor, Ceiling, Modulo & Hash

Concept 4.1

ฟังก์ชันพื้น (Floor $\lfloor x \rfloor$) และเพดาน (Ceiling $\lceil x \rceil$)

FLOOR ฟังก์ชันพื้น $\lfloor x \rfloor$
จำนวนเต็มที่มากที่สุดที่ $\le x$ (ปัดลง):
• $\lfloor 3.8 \rfloor = 3$
• $\lfloor 3.0 \rfloor = 3$
• $\lfloor -3.2 \rfloor = \mathbf{-4}$
CEILING ฟังก์ชันเพดาน $\lceil x \rceil$
จำนวนเต็มที่น้อยที่สุดที่ $\ge x$ (ปัดขึ้น):
• $\lceil 3.2 \rceil = 4$
• $\lceil 3.0 \rceil = 3$
• $\lceil -3.8 \rceil = \mathbf{-3}$
COMP การแบ่งหน้าข้อมูล (Pagination)
มีบทความ $N = 127$ รายการ แสดงหน้าละ $S = 10$ รายการ $\implies$ ต้องใช้จำนวนหน้าทั้งหมด $= \lceil 127 / 10 \rceil = \mathbf{13 \text{ หน้า}}$

Concept 4.2

ฟังก์ชันมอดุโล (Modulo) และฟังก์ชันแฮช (Hash Function)

MOD ฟังก์ชันมอดุโล ($a \bmod m$)
เศษที่เหลือจากการหาร $a$ ด้วย $m$ ($0 \le r < m$):
• $17 \bmod 5 = 2$
• $-8 \bmod 3 = 1$
• Circular Queue: $(\text{index} + 1) \bmod N$
HASH ฟังก์ชันแฮช $h(k) = k \bmod m$
แปลงคีย์ข้อมูลขนาดใหญ่ให้เป็นดัชนีช่องตารางขนาด $m$:
• $h(24) = 24 \bmod 7 = 3$
• $h(15) = 15 \bmod 7 = 1$
• Collision: $h(50) = 50 \bmod 7 = 1$ (ชนกับ 15!)

Concept 4.3

ฟังก์ชันแบบเรียกซ้ำ (Recursive Functions & Call Stack)

DEF โครงสร้างฟังก์ชันเรียกซ้ำ
1. กรณีฐาน (Base Case): เงื่อนไขหยุด คืนคำตอบทันที
2. ขั้นตอนเรียกซ้ำ (Recursive Step): ลดขนาดปัญหาเข้าหา Base Case
EX แฟกทอเรียล ($n!$)
$$f(n) = \begin{cases} 1 & n = 0 \text{ (Base)} \\ n \cdot f(n-1) & n \ge 1 \end{cases}$$
STACK Call Stack Trace บน Memory
$f(3) \to 3 \cdot f(2)$
$\quad \to 2 \cdot f(1)$
$\quad\quad \to 1 \cdot f(0) \implies \text{Base: } 1$
$\quad \leftarrow 2 \cdot 1 = 2$
$\leftarrow 3 \cdot 2 = \mathbf{6}$
