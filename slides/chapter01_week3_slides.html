PART 01

ประพจน์เปิดOpen Propositions — ปูพื้นฐานก่อนเข้าเรื่องตัวบ่งปริมาณ

เนื้อหาระดับมัธยมปลาย — เริ่มจากสิ่งที่คุ้นเคย
พื้นฐาน · Concept 1

ประพจน์เปิด (Open Proposition) คืออะไร?

นิยาม ประพจน์เปิด คือประโยคที่มี ตัวแปร (เช่น x) ยังไม่ระบุค่า ทำให้ไม่สามารถระบุค่าความจริงได้ จนกว่าจะแทนค่าตัวแปร
ตัวอย่างจากชีวิตประจำวัน:
  • x เป็นเลขคู่
  • x² = 4
  • x อายุมากกว่า 18 ปี
  • x เป็นนักศึกษามหาวิทยาลัย
คณิตศาสตร์สำหรับคอมพิวเตอร์◆บทที่ 1 ตรรกศาสตร์
พื้นฐาน · Concept 2

ปัญหาของประพจน์เปิด: จริงหรือเท็จ?

ปัญหา ประพจน์ "x เป็นเลขคู่" — จริงหรือเท็จ?
คำตอบ: ขึ้นอยู่กับค่า x
กรณี A ถ้า x = 2
"2 เป็นเลขคู่" ⇒ T จริง
กรณี B ถ้า x = 3
"3 เป็นเลขคู่" ⇒ F เท็จ
ทางออก เราต้องมี "ตัวบ่งปริมาณ" (Quantifier) มาช่วยปิดประพจน์เปิด ให้กลายเป็นประพจน์ที่ตัดสินค่าความจริงได้

PART 02

ตัวบ่งปริมาณ (∀, ∃)Universal & Existential Quantifiers — ระดับมัธยมปลาย

เครื่องมือพื้นฐานที่ใช้ปิดประพจน์เปิด
Concept 3 · ∀

∀ (Universal) — "สำหรับทุกตัว"

นิยาม
∀x [P(x)]
อ่านว่า "สำหรับทุก x ในเอกภพ ประพจน์ P(x) เป็นจริง"
จริง ⇔ ทุกค่า x ในเอกภพ ทำให้ P(x) เป็นจริง
ตัวอย่าง:
  • ∀x ∈ ℕ [x ≥ 0] — "จำนวนธรรมชาติทุกตัว ≥ 0" (จริง)
  • ∀x ∈ {1,2,3} [x > 0] — "ทุกตัวใน {1,2,3} มากกว่า 0" (จริง)
  • ∀x ∈ {1,2,3} [x > 2] — "ทุกตัวใน {1,2,3} มากกว่า 2" (เท็จ เพราะ 1 ≯ 2)
คณิตศาสตร์สำหรับคอมพิวเตอร์◆บทที่ 1 ตรรกศาสตร์
Concept 4 · ∃

∃ (Existential) — "มีบางตัว"

นิยาม
∃x [P(x)]
อ่านว่า "มี x อย่างน้อยหนึ่งตัวในเอกภพ ที่ทำให้ P(x) เป็นจริง"
จริง ⇔ มีค่า x สักตัวในเอกภพ ที่ทำให้ P(x) เป็นจริง
ตัวอย่าง:
  • ∃x ∈ {1,2,3} [x เป็นคู่] — "ใน {1,2,3} มีเลขคู่" (จริง เพราะ x=2)
  • ∃x ∈ ℝ [x² = 4] — "มีจำนวนจริงที่ยกกำลังสองได้ 4" (จริง เพราะ x=2)
  • ∃x ∈ {1,3,5} [x เป็นคู่] — "ใน {1,3,5} มีเลขคู่" (เท็จ)
คณิตศาสตร์สำหรับคอมพิวเตอร์◆บทที่ 1 ตรรกศาสตร์
Concept 5

เอกภพสัมพัทธ์ (Universe of Discourse)

นิยาม เอกภพสัมพัทธ์ (Universe, U) คือ เซตของค่าทั้งหมด ที่ตัวแปร x สามารถแทนค่าได้
เขียนในรูป ∀x ∈ U หรือ ∃x ∈ U
ตัวอย่างเอกภพที่พบบ่อย:
สัญลักษณ์ความหมายตัวอย่างสมาชิก
ℕจำนวนธรรมชาติ0, 1, 2, 3, ...
ℤจำนวนเต็ม..., -2, -1, 0, 1, 2, ...
ℚจำนวนตรรกยะ1/2, -3/4, 0.5, ...
ℝจำนวนจริง-1.5, 0, √2, π, ...
{1,2,3}เซตจำกัด1, 2, 3
⚠ สำคัญ: ∀x (x > 0) บน ℕ ≠ บน ℤ
คณิตศาสตร์สำหรับคอมพิวเตอร์◆บทที่ 1 ตรรกศาสตร์
Concept 6

เปรียบเทียบ ∀ vs ∃ ในชีวิตจริง

∀x [P(x)]
"ทุกตัว" · "ทั้งหมด"
  • "นักศึกษาทุกคนสอบผ่าน"
  • "ทุกจังหวัดมีโรงพยาบาล"
  • "ทุกเลขคู่หาร 2 ลงตัว"

"บางตัว" · "อย่างน้อยหนึ่ง"
  • "มีนักศึกษาบางคนได้ A"
  • "มีจังหวัดบางจังหวัดติดทะเล"
  • "มีเลขคี่บางตัวที่หาร 5 ลงตัว"

การหาค่าความจริงEvaluation — ระดับกลาง

ลงมือตรวจสอบจริง: ∀x [P(x)] จริงเมื่อไร? ∃x [P(x)] จริงเมื่อไร?
ตรวจสอบ · ∀x [P(x)]

วิธีหาค่า ∀x [P(x)] (Step-by-Step)

สูตร
∀x ∈ U [P(x)]
จริง ⇔ ทุกค่า x ใน U ให้ P(x) = T
เท็จ ⇔ มีค่า x แค่ตัวเดียวใน U ที่ให้ P(x) = F
ขั้นตอน:
1
ระบุเอกภพ U และสมาชิกทั้งหมด
2
ตรวจ P(x) ทีละตัวใน U (เริ่มจากตัวแรก)
3
ถ้าทุกตัวเป็น T ⇒ ∀x [P(x)] = T
4
ถ้ามีตัวเดียวเป็น F ⇒ ∀x [P(x)] = F (จบทันที)

ตัวอย่างค้าน (Counterexample)กลาง-สูง

∀ เท็จไม่จำเป็นต้องตรวจทุกตัว — หาตัวอย่างค้านตัวเดียวก็พอ
หลักการ

ตัวอย่างค้าน (Counterexample) ใช้เมื่อไร?

หลักการ ∀
∀x [P(x)] เป็น F ⟺ ∃x [¬P(x)]
แสดงว่า ∀x [P(x)] เป็นเท็จ ⇒ หา ตัวอย่างค้าน เพียง 1 ตัว ที่ทำให้ P(x) เป็นเท็จ
หลักการ ∃
∃x [P(x)] เป็น T ⟺ หาตัวอย่างยืนยัน 1 ตัว
แสดงว่า ∃x [P(x)] เป็นจริง ⇒ หา ตัวอย่างยืนยัน เพียง 1 ตัว ที่ทำให้ P(x) เป็นจริง
⚠ ใช้ "ตัวอย่างเดียว" พอ — ไม่ต้องตรวจสมาชิกทั้งหมดในเอกภพ
คณิตศาสตร์สำหรับคอมพิวเตอร์◆บทที่ 1 ตรรกศาสตร์
ตัวอย่าง · ∀x [x > 0] บน ℤ

∀x ∈ ℤ [x > 0] — เท็จ! หาตัวอย่างค้าน

โจทย์ เอกภพ: U = ℤ (จำนวนเต็ม)  |  ประพจน์: P(x) = x > 0
ลองหาตัวอย่างค้าน (ตัวที่ทำให้ P(x) = F):
ลอง xx > 0เป็นตัวอย่างค้าน?
x = 55 > 0 = จริงไม่ใช่ (ยังจริงอยู่)
x = 00 > 0 = เท็จเป็น! ✓
x = -5-5 > 0 = เท็จเป็น! ✓
x = -100-100 > 0 = เท็จเป็น! ✓
สรุป: ∀x ∈ ℤ [x > 0] เป็น F
ตัวอย่างค้าน: x = 0 (หรือ x = -5, -100, ... — เจอตัวเดียวก็พอ)

PART 05

นิเสธของตัวบ่งปริมาณNegation — ระดับสูง

สลับตัวบ่งปริมาณ + กลับประพจน์ย่อย — เคล็ดลับเดียวจำได้ทั้งชีวิต
สูตรนิเสธ

นิเสธของ ∀ และ ∃ (สูตรสำคัญ)

ทำไมต้องเรียนนิเสธ? — เมื่อต้องการแสดงว่าประพจน์เป็นเท็จ หรือโต้แย้งข้อความที่มีตัวบ่งปริมาณ
สูตรที่ 1 · นิเสธของ ∀
¬(∀x [P(x)]) ≡ ∃x [¬P(x)]
อ่านว่า "ไม่ใช่ว่าทุกตัวเป็นจริง" = "มีบางตัวที่เป็นเท็จ"
สูตรที่ 2 · นิเสธของ ∃
¬(∃x [P(x)]) ≡ ∀x [¬P(x)]
อ่านว่า "ไม่มีสักตัวที่เป็นจริง" = "ทุกตัวเป็นเท็จ"
เคล็ดลับจำ 2 ขั้น: ① สลับตัวบ่งปริมาณ ∀ ↔ ∃ ② ใส่นิเสธให้ประพจน์ข้างใน: P(x) → ¬P(x)
ตัวอย่างเร็ว "ทุกคนมาเรียน"  → นิเสธ →  "มีบางคนไม่มาเรียน"   |   "มีคนทำข้อสอบเต็ม"  → นิเสธ →  "ทุกคนทำข้อสอบไม่เต็ม"
คณิตศาสตร์สำหรับคอมพิวเตอร์◆บทที่ 1 ตรรกศาสตร์
ตัวอย่าง · นิเสธ

เขียนนิเสธในภาษาไทย (Step-by-Step)

ตัวอย่างที่ 1 · นิเสธ ∀
ประโยค: "นักศึกษาทุกคนสอบผ่าน"
∀x ∈ นักศึกษา [สอบผ่าน]
นิเสธ: "มีนักศึกษาบางคนสอบไม่ผ่าน"
∃x ∈ นักศึกษา [¬สอบผ่าน]
ตัวอย่างที่ 2 · นิเสธ ∃
ประโยค: "มีนกที่บินไม่ได้"
∃x ∈ นก [¬บินได้]
นิเสธ: "นกทุกตัวบินได้"
∀x ∈ นก [บินได้]
ตัวอย่างที่ 3 · ระวังนิเสธซ้อน ประโยค: "ไม่มีจำนวนจริงที่ยกกำลังสองแล้วติดลบ"  ⇒  ¬(∃x ∈ ℝ [x² < 0])
นิเสธ (เขียนใหม่): "จำนวนจริงทุกตัวยกกำลังสองแล้วไม่ติดลบ"  ⇒  ∀x ∈ ℝ [x² ≥ 0]
⚠ ข้อควรระวัง: นิเสธของ "ไม่ผ่าน" คือ "ผ่าน" (นิเสธซ้อนหักล้างกัน) · เมื่อกลับตัวบ่งปริมาณ ต้องกลับประพจน์ข้างในด้วยเสมอ

PART 06

ประยุกต์: ตัวบ่งปริมาณซ้อนApplication — ระดับสูงมาก

เมื่อมีตัวบ่งปริมาณมากกว่า 1 ตัว — ลำดับสำคัญมาก
ตัวบ่งปริมาณซ้อน · ∀x, ∃y

ตัวบ่งปริมาณซ้อน (Nested) — ลำดับสำคัญ!

เมื่อมีตัวแปร 2 ตัว (x, y) ใช้ตัวบ่งปริมาณคั่นด้วยเครื่องหมายจุลภาค (,) — ลำดับที่วางมีความหมายต่างกัน
แบบที่ 1 · ∀ ก่อน ∃
∀x, ∃y [P(x,y)]
"ทุกคนมีคนรู้จัก" — สำหรับทุก x มี y ที่รู้จัก x
y อาจขึ้นกับ x (แต่ละคนเลือก y คนละคนได้)
แบบที่ 2 · ∃ ก่อน ∀
∃x, ∀y [P(x,y)]
"มีคนที่รู้จักทุกคน" — มี x ตัวเดียวที่รู้จัก y ทุกตัว
x เป็นตัวเดียวตายตัว (คนเดียวที่รู้จักทุกคน)
⚠ ลำดับสำคัญมาก!  ∀x, ∃y ≠ ∃y, ∀x  — สลับลำดับแล้วความหมายเปลี่ยนโดยสิ้นเชิง
คณิตศาสตร์สำหรับคอมพิวเตอร์◆บทที่ 1 ตรรกศาสตร์
การประยุกต์ใช้งาน

ตัวบ่งปริมาณในงานวิทยาการคอมพิวเตอร์

1. ฐานข้อมูล (SQL)
∃ ⇒ EXISTS  |  ∀ ⇒ NOT EXISTS
"มีลูกค้าที่สั่งซื้อ > 1000 บาท":
SELECT * FROM cust c WHERE EXISTS
(SELECT 1 FROM ord WHERE cid=c.id
 AND amt>1000)
2. การเขียนโปรแกรม
∀ ⇒ all() ตรวจทุกตัว  |  ∃ ⇒ any() เจอตัวแรกหยุด
Python:
all(x > 0 for x in nums)  # ∀
any(x == 0 for x in nums) # ∃

แบบที่ 1 · แปลง "ไม่มี" โจทย์: "ไม่มีนักศึกษาคนใดขาดสอบ"

Recap · สรุป

สรุป: ตัวบ่งปริมาณ (Quantifiers)

1. ∀ (Universal) — "สำหรับทุกตัว"
∀x [P(x)] จริง ⇔ ทุกค่า x ในเอกภพให้ P(x) = T
2. ∃ (Existential) — "มีบางตัว"
∃x [P(x)] จริง ⇔ มีค่า x สักตัวในเอกภพที่ให้ P(x) = T
3. เอกภพสัมพัทธ์ (U) — สำคัญมาก
∀x [P(x)] บน ℕ ≠ ∀x [P(x)] บน ℤ — เอกภพเปลี่ยน คำตอบเปลี่ยน
4. ตัวอย่างค้าน (Counterexample)
∀x [P(x)] เท็จ ⟺ มีตัวอย่างค้าน 1 ตัว — ไม่ต้องตรวจทุกตัว
5. นิเสธ (Negation)
¬(∀x [P(x)]) ≡ ∃x [¬P(x)]  |  ¬(∃x [P(x)]) ≡ ∀x [¬P(x)]
