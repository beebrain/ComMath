คู่อันดับและผลคูณคาร์ทีเซียนOrdered Pairs & Cartesian Products

Concept 1.1

คู่อันดับ (Ordered Pair)

DEF นิยามคู่อันดับ $(a, b)$
คู่อันดับระบุการจับคู่ที่มี ทิศทางและลำดับที่แน่นอน โดย $a$ เป็นสมาชิกตัวหน้า และ $b$ เป็นสมาชิกตัวหลัง
EQUIV เงื่อนไขการเท่ากันของคู่อันดับ
$$\mathbf{(a, b) = (c, d) \iff a = c \land b = d}$$
CAUTION ข้อควรระวัง
ลำดับมีผลต่อความหมายโดยตรง: $\mathbf{(a, b) \neq (b, a)}$ เมื่อ $a \neq b$ (เช่น พิกัด $(2, 5) \neq (5, 2)$ บนแกน $x, y$)

Concept 1.2

ผลคูณคาร์ทีเซียน (Cartesian Product)

DEF ผลคูณคาร์ทีเซียน $A \times B$
เซตของคู่อันดับ $(a, b)$ ทั้งหมดโดยที่ $a \in A$ และ $b \in B$: $$\mathbf{A \times B = \{(a, b) \mid a \in A \land b \in B\}}$$
EXAMPLE ตัวอย่างการแจกแจง
กำหนด $A = \{1, 2\}$ และ $B = \{x, y, z\}$
$$\mathbf{A \times B = \{(1, x), (1, y), (1, z), (2, x), (2, y), (2, z)\}}$$

Concept 1.3

การคำนวณจำนวนสมาชิกในผลคูณคาร์ทีเซียน

FORMULA กฎการคูณจำนวนสมาชิก
ถ้าเซต $A$ มีสมาชิก $m$ ตัว และเซต $B$ มีสมาชิก $n$ ตัว: $$\mathbf{|A \times B| = |A| \cdot |B| = m \cdot n}$$
EX ตัวอย่างคำนวณ
• ให้ $A = \{1, 2, 3\}$ ($|A| = 3$) และ $B = \{x, y\}$ ($|B| = 2$)
• $|A \times B| = 3 \times 2 = \mathbf{6}$ สมาชิก
• $|A \times A| = 3 \times 3 = \mathbf{9}$ สมาชิก (ผลคูณทวิภาคบน $A$)

Concept 1.4

สมบัติการกระจายของผลคูณคาร์ทีเซียน

LAWS กฎการกระจายข้ามยูเนียนและอินเตอร์เซกชัน
$$\mathbf{A \times (B \cup C) = (A \times B) \cup (A \times C)}$$ $$\mathbf{A \times (B \cap C) = (A \times B) \cap (A \times C)}$$ $$\mathbf{(A \cup B) \times C = (A \times C) \cup (B \times C)}$$ $$\mathbf{(A \cap B) \times C = (A \times C) \cap (B \times C)}$$
KEY ความสำคัญในคอมพิวเตอร์
สมบัติการกระจายนี้ถูกใช้ในการ ปรับแต่งคิวรีฐานข้อมูล (Query Optimization) เพื่อลดขนาดตารางชั่วคราวก่อนทำการ Join

Concept 2.1

นิยามความสัมพันธ์ (Binary Relation)

DEF ความสัมพันธ์จาก $A$ ไป $B$
ความสัมพันธ์ $R$ จากเซต $A$ ไปยังเซต $B$ คือ เซตย่อยใดๆ ของผลคูณคาร์ทีเซียน $A \times B$: $$\mathbf{R \subseteq A \times B}$$ • ถ้า $(a, b) \in R$ เรากล่าวว่า $a$ มีความสัมพันธ์ $R$ กับ $b$ (เขียนแทนด้วย $a \, R \, b$)
• ถ้า $(a, b) \notin R$ เรากล่าวว่า $a$ ไม่มีความสัมพันธ์ $R$ กับ $b$ (เขียนแทนด้วย $a \not R \, b$)
COUNT จำนวนความสัมพันธ์ที่เป็นไปได้ทั้งหมด
เนื่องจาก $R$ คือเซตย่อยของ $A \times B$ ดังนั้นจำนวนความสัมพันธ์ทั้งหมดจึงเท่ากับเพาเวอร์เซต: $$\mathbf{\text{จำนวนความสัมพันธ์จาก } A \text{ ไป } B = 2^{|A \times B|} = 2^{|A| \cdot |B|}}$$

Concept 2.2

การแทนด้วยเมทริกซ์บูลีน 0-1 (Relation Matrix $M_R$)

DEF กฎการสร้างเมทริกซ์ $M_R$
กำหนดแถวแทนสมาชิกใน $A$ และคอลัมน์แทนสมาชิกใน $B$: $$M_R[i, j] = \begin{cases} 1 & \text{ถ้า } (a_i, b_j) \in R \\ 0 & \text{ถ้า } (a_i, b_j) \notin R \end{cases}$$
EX ตัวอย่าง
ให้ $A = \{1, 2, 3\}$ และ $R = \{(1, 2), (1, 3), (2, 3), (3, 1)\}$: $$\mathbf{M_R = \begin{bmatrix} 0 & 1 & 1 \\ 0 & 0 & 1 \\ 1 & 0 & 0 \end{bmatrix}}$$ ✓ บิต 1 แทนการเชื่อมโยง / บิต 0 แทนไม่มีการเชื่อมโยง

Concept 2.3

การแทนด้วยกราฟระบุทิศทาง (Digraph) และแผนภาพลูกศร

GRAPH กราฟระบุทิศทาง (Directed Graph / Digraph)
• จุดยอด (Vertices): แทนสมาชิกแต่ละตัวในเซต $A$
• เส้นเชื่อมระบุทิศทาง (Directed Edges): ลากจาก $u \to v$ เมื่อ $(u, v) \in R$
• ลูป (Self-loop): เส้นโค้งวนกลับหาตัวเองเมื่อ $(u, u) \in R$
ARROW แผนภาพลูกศร (Arrow Diagram)
• วางเซตต้นทาง $A$ และปลายทาง $B$ ในแนวขนาน
• ลากเส้นลูกศรเชื่อมข้ามเซตจากซ้ายไปขวา
• เหมาะมากสำหรับการตรวจดู โดเมน เรนจ์ และทิศทางการจับคู่

โดเมน เรนจ์ และความสัมพันธ์ผกผันDomain, Range, Inverse & Set Operations

Concept 3.1

โดเมน (Domain) และเรนจ์ (Range) ของความสัมพันธ์

DEF โดเมน $\operatorname{Dom}(R)$
เซตของสมาชิกตัวหน้าทั้งหมดที่ปรากฏใน $R$: $$\mathbf{\operatorname{Dom}(R) = \{a \in A \mid \exists b \in B, (a, b) \in R\} \subseteq A}$$
DEF เรนจ์ $\operatorname{Ran}(R)$
เซตของสมาชิกตัวหลังทั้งหมดที่ปรากฏใน $R$: $$\mathbf{\operatorname{Ran}(R) = \{b \in B \mid \exists a \in A, (a, b) \in R\} \subseteq B}$$
EXAMPLE ตัวอย่างการหาโดเมนและเรนจ์
ให้ $A = \{1, 2, 3, 4\}$ และ $B = \{x, y, z\}$
$R = \{(1, x), (2, y), (3, x)\}$

• $\mathbf{\operatorname{Dom}(R) = \{1, 2, 3\}}$ (หมายเหตุ: 4 ไม่อยู่ในโดเมน)
• $\mathbf{\operatorname{Ran}(R) = \{x, y\}}$ (หมายเหตุ: z ไม่อยู่ในเรนจ์)

Concept 3.2

ความสัมพันธ์ผกผัน (Inverse Relation $R^{-1}$)

DEF นิยามความสัมพันธ์ผกผัน
สลับตำแหน่งสมาชิกตัวหน้าและตัวหลังในทุกคู่อันดับของ $R$: $$\mathbf{R^{-1} = \{(b, a) \in B \times A \mid (a, b) \in R\}}$$ $$\mathbf{\operatorname{Dom}(R^{-1}) = \operatorname{Ran}(R), \quad \operatorname{Ran}(R^{-1}) = \operatorname{Dom}(R)}$$
MATRIX เมทริกซ์สลับเปลี่ยน (Transpose)
ในรูปเมทริกซ์บูลีน 0-1 เมทริกซ์ของความสัมพันธ์ผกผันคือ การ Transpose แถวเป็นคอลัมน์: $$\mathbf{M_{R^{-1}} = M_R^T}$$

4 สมบัติทวิภาค & ตัวอย่างเชิงตัวเลขBinary Properties & Numerical Insights

Concept 4.1

สมบัติสะท้อน (Reflexive Property)

DEF นิยามสมบัติสะท้อน
สมาชิกทุกตัวในเซต $A$ ต้องสัมพันธ์กับตัวเอง: $$\mathbf{\forall x \in A, (x, x) \in R}$$ • ในเมทริกซ์: เส้นทแยงมุมหลักเป็น 1 ทั้งหมด ($M_{ii} = 1$ ทุก $i$)
• ในกราฟ: ทุกโหนดต้องมีลูปวนหาตัวเอง (Self-loop) ครบทุกตัว
✓ เป็นสะท้อน ตัวอย่างเชิงตัวเลข
• $a \le b$ บน $\mathbb{Z}$: $5 \le 5$ (จริง) เสมอ $\implies (5,5) \in R$
• $a \mid b$ บน $\mathbb{Z}^+$: $4 \mid 4$ (จริง) เสมอ $\implies (4,4) \in R$
✗ ไม่เป็นสะท้อน ตัวอย่างเชิงตัวเลข
• $a < b$ บน $\mathbb{Z}$: $5 < 5$ เป็น เท็จ $\implies (5,5) \notin R$
• $a + b = 10$: $3 + 3 = 6 \neq 10 \implies (3,3) \notin R$

Concept 4.2

สมบัติสมมาตร (Symmetric Property)

DEF นิยามสมบัติสมมาตร
ถ้ามีคู่อันดับไป จะต้องมีคู่อันดับกลับมาเสมอ: $$\mathbf{\forall x, y \in A, (x, y) \in R \implies (y, x) \in R}$$ • ในเมทริกซ์: เมทริกซ์สมมาตร $\mathbf{M_R = M_R^T}$ (พับตามแนวทแยงแล้วเท่ากัน)
• ในกราฟ: เส้นเชื่อมระหว่างสองโหนดใดๆ ต้องเป็นลูกศรสองหัวไปกลับเสมอ
✓ เป็นสมมาตร ตัวอย่างเชิงตัวเลข
• $a + b$ เป็นเลขคู่: $(1, 3) \in R \implies (3, 1) \in R$ ($1+3=3+1=4$)
• $a \equiv b \pmod 4$: $(10, 2) \in R \implies (2, 10) \in R$
✗ ไม่เป็นสมมาตร ตัวอย่างเชิงตัวเลข
• $a \le b$: มี $(2, 5) \in R$ แต่ $(5, 2) \notin R$ ($5 \le 2$ เป็นเท็จ)
• $a \mid b$: มี $(2, 6) \in R$ แต่ $(6, 2) \notin R$ ($6 \nmid 2$)

Concept 4.3

สมบัติปฏิสมมาตร (Antisymmetric Property)

DEF นิยามสมบัติปฏิสมมาตร
ถ้ามีคู่อันดับไปและกลับพร้อมกัน สมาชิกทั้งสองตัวนั้นต้องเป็นตัวเดียวกันเท่านั้น: $$\mathbf{\forall x, y \in A, ((x, y) \in R \land (y, x) \in R) \implies x = y}$$ • ความหมายง่ายๆ: ถ้า $x \neq y$ ห้ามมีลูกศรสองหัวไปกลับพร้อมกันเด็ดขาด!
✓ เป็นปฏิสมมาตร ตัวอย่างเชิงตัวเลข
• $a \le b$: ถ้า $a \le b$ และ $b \le a$ จะเกิดขึ้นได้เมื่อ $a = b$ เท่านั้น
• $a \mid b$ บน $\mathbb{Z}^+$: $(2, 6) \in R$ แต่ไม่มี $(6, 2) \in R$
✗ ไม่เป็นปฏิสมมาตร ตัวอย่างเชิงตัวเลข
• $a + b = 10$: มี $(4, 6) \in R$ และ $(6, 4) \in R$ แต่ $4 \neq 6$
• $a \equiv b \pmod 3$: มี $(7, 1) \in R$ และ $(1, 7) \in R$ แต่ $7 \neq 1$

Concept 4.4

เจาะลึก: สมมาตร vs ปฏิสมมาตร (4 รูปแบบที่เป็นไปได้)

CASE 1 เป็นทั้งสมมาตร และปฏิสมมาตร
$\Delta = \{(1, 1), (2, 2), (3, 3)\}$ (ความสัมพันธ์เอกลักษณ์)
มีเฉพาะบนแนวทแยง ไม่มีคู่อื่นให้ขัดแย้งเลย
CASE 2 เป็นสมมาตร แต่ไม่เป็นปฏิสมมาตร
$R = \{(1, 2), (2, 1)\}$
มีลูกศรสองหัว $1 \leftrightarrow 2$ จึงสมมาตร แต่ผิดปฏิสมมาตร
CASE 3 ไม่เป็นสมมาตร แต่เป็นปฏิสมมาตร
$R = \{(1, 2), (2, 3)\}$
มีลูกศรทางเดียว ไม่มีลูกศรสองหัว จึงเป็นปฏิสมมาตร
CASE 4 ไม่เป็นทั้งสองสมบัติ
$R = \{(1, 2), (2, 1), (2, 3)\}$
มีคู่ $(2, 3)$ ขาด $(3, 2)$ และมีคู่ $(1, 2), (2, 1)$ ขัดแย้ง

Concept 4.5

สมบัติถ่ายทอด (Transitive Property)

DEF นิยามสมบัติถ่ายทอด
ถ้าเดินทางจาก $x \to y$ และ $y \to z$ ได้ จะต้องมีทางลัดตรง $x \to z$ ในความสัมพันธ์เสมอ: $$\mathbf{\forall x, y, z \in A, ((x, y) \in R \land (y, z) \in R) \implies (x, z) \in R}$$
✓ เป็นถ่ายทอด ตัวอย่างเชิงตัวเลข
• $a < b$: $(2 < 5 \land 5 < 9) \implies 2 < 9$ (จริงเสมอ)
• $a \mid b$: $(2 \mid 6 \land 6 \mid 18) \implies 2 \mid 18$ (จริงเสมอ)
• $a \equiv b \pmod 5$: $(17 \equiv 7 \land 7 \equiv 2) \implies 17 \equiv 2 \pmod 5$
✗ ไม่เป็นถ่ายทอด กรณีขัดแย้ง (Counter-example)
• $|a - b| \le 2$:
$(1, 3) \in R$ ($|1-3|=2$) และ $(3, 5) \in R$ ($|3-5|=2$)
แต่ $(1, 5) \notin R$ เพราะ $|1-5|=4 > 2$! (หลุดขอบเขต)

ความสัมพันธ์สมมูลและผลกั้นเซตEquivalence Relations & Partitions

Concept 5.1

ความสัมพันธ์สมมูล (Equivalence Relation)

DEF นิยามความสัมพันธ์สมมูล
ความสัมพันธ์ $R$ บนเซต $A$ จะเป็น ความสัมพันธ์สมมูล ก็ต่อเมื่อมีครบทั้ง 3 สมบัติดังนี้: $$\mathbf{\text{1. สะท้อน (Reflexive)}} \quad \mathbf{\text{2. สมมาตร (Symmetric)}} \quad \mathbf{\text{3. ถ่ายทอด (Transitive)}}$$
ROLE บทบาทในวิทยาการข้อมูล
ความสัมพันธ์สมมูลใช้ในการ จัดกลุ่มข้อมูล (Data Clustering / Classification) โดยสมาชิกที่มีคุณสมบัติร่วมกันจะถูกจัดไว้ในกลุ่มเดียวกัน

Concept 5.2

คลาสสมมูล (Equivalence Class) และผลกั้นเซต

DEF คลาสสมมูล $[a]$
เซตของสมาชิกทั้งหมดใน $A$ ที่มีความสัมพันธ์กับ $a$: $$\mathbf{[a] = \{x \in A \mid (a, x) \in R\}}$$
THEOREM ทฤษฎีบทผลกั้นเซต (Partition Theorem)
คลาสสมมูลจะแบ่งเซต $A$ ออกเป็นกลุ่มย่อยที่ไม่ซ้อนทับกัน: $$\text{1. } [a] \neq \emptyset \quad \text{2. } [a] = [b] \lor [a] \cap [b] = \emptyset \quad \text{3. } \bigcup [a] = A$$

Concept 5.3

ตัวอย่างเชิงตัวเลข: ผลกั้นเซตของมอดุโล 3

EXAMPLE บนเซต $A = \{0, 1, 2, 3, 4, 5, 6, 7\}$ สำหรับ $a \equiv b \pmod 3$
• กลุ่มเศษ 0: $[0] = \{x \in A \mid x \equiv 0 \pmod 3\} = \mathbf{\{0, 3, 6\}}$
• กลุ่มเศษ 1: $[1] = \{x \in A \mid x \equiv 1 \pmod 3\} = \mathbf{\{1, 4, 7\}}$
• กลุ่มเศษ 2: $[2] = \{x \in A \mid x \equiv 2 \pmod 3\} = \mathbf{\{2, 5\}}$
VERIFY ตรวจสอบผลกั้น
$$[0] \cup [1] \cup [2] = \{0, 1, 2, 3, 4, 5, 6, 7\} = A \quad \text{และ} \quad [0] \cap [1] = [1] \cap [2] = [0] \cap [2] = \emptyset$$

การประกอบความสัมพันธ์และการปิดสมบัติComposition & Closures (Warshall)

Concept 6.1

การประกอบความสัมพันธ์ (Composition $S \circ R$)

DEF นิยามการประกอบ $S \circ R$
ให้ $R \subseteq A \times B$ และ $S \subseteq B \times C$
$$\mathbf{S \circ R = \{(a, c) \mid \exists b \in B, (a, b) \in R \land (b, c) \in S\}}$$ • ลำดับการทำงาน: ทำความสัมพันธ์ $R$ ก่อน แล้วเชื่อมต่อด้วย $S$
MATRIX การคูณเมทริกซ์บูลีน (Boolean Matrix Product)
$$\mathbf{M_{S \circ R} = M_R \odot M_S}$$ $$c_{ij} = (a_{i1} \land b_{1j}) \lor (a_{i2} \land b_{2j}) \lor \dots \lor (a_{ik} \land b_{kj})$$

Concept 6.2

การปิดสมบัติ (Reflexive, Symmetric & Transitive Closures)

1 การปิดสมบัติสะท้อน
เติมแนวทแยง $\Delta$ ทั้งหมด:
$$\mathbf{R \cup \Delta}$$
2 การปิดสมบัติสมมาตร
เติมคู่สลับ $R^{-1}$ เข้าไป:
$$\mathbf{R \cup R^{-1}}$$
3 การปิดสมบัติถ่ายทอด
รวมทุกความยาวเส้นทาง:
$$\mathbf{R^+ = \bigcup_{k=1}^n R^k}$$
ALGO ขั้นตอนวิธีวอร์แชลล์ (Warshall's Algorithm)
คำนวณ Transitive Closure ($R^+$) หรือ Reachability ในกราฟ ด้วยความซับซ้อน $O(n^3)$ มีประสิทธิภาพสูงกว่าการคูณเมทริกซ์ตรงๆ
