สัจนิรันดร์ ข้อขัดแย้ง และประพจน์กลางPropositions Categorization

ประเภทประพจน์ · Categorization

จำแนกประพจน์เชิงประกอบ 3 ประเภท

Tautology สัจนิรันดร์ — มีค่าความจริงเป็น จริงในทุกกรณี ไม่ว่าตัวแปรย่อยจะมีค่าความจริงเป็นอย่างไร
Contradiction ข้อขัดแย้ง — มีค่าความจริงเป็น เท็จในทุกกรณี ไม่ว่าตัวแปรย่อยจะมีค่าความจริงเป็นอย่างไร
Contingency ประพจน์กลาง — มีค่าความจริงเป็น จริงบ้าง เท็จบ้าง ขึ้นกับค่าของประพจน์ย่อย
ข้อสังเกตความสัมพันธ์:
  • นิเสธของสัจนิรันดร์ คือ ข้อขัดแย้ง
  • นิเสธของข้อขัดแย้ง คือ สัจนิรันดร์
  • ประพจน์ส่วนใหญ่ในชีวิตจริงมักเป็น ประพจน์กลาง เช่น "วันนี้ฝนตก"

การประยุกต์ใช้ในคอมพิวเตอร์ · Application

ทำไมชีวิตจริงและโปรแกรมมิ่งจึงต้องใช้ "ประพจน์กลาง"?

ในชีวิตจริงและวิทยาการคอมพิวเตอร์ เงื่อนไขการตัดสินใจเกือบทั้งหมดเป็น ประพจน์กลาง (Contingency) เพราะต้องการความยืดหยุ่นตามข้อมูลอินพุต
ตัวแปรยืดหยุ่น (Dynamic Decision) เงื่อนไขทั่วไปในการเขียนโปรแกรม:
  • age >= 18 — จริงหรือเท็จ ขึ้นกับอายุผู้ใช้
  • password == hash — จริงเฉพาะเมื่อรหัสถูก
  • balance >= price — จริงเมื่อเงินในบัญชีพอ
ตรรกะคงที่ (Static Logic) หากเงื่อนไขเป็นสัจนิรันดร์ หรือข้อขัดแย้ง:
  • if (true) หรือ if (x == x) — จริงตลอดเวลา โค้ดจะทำงานทางเดิมเสมอ (ไม่มีการตัดสินใจ)
  • if (false) หรือ if (x && !x) — เท็จตลอดเวลา เกิด Dead Code (โค้ดที่ไม่มีวันถูกรัน)

นิยาม ประพจน์เชิงประกอบที่มีค่าความจริงเป็น จริงในทุกกรณี (T)
ตัวอย่างคลาสสิก: p ∨ ¬p (กฎกีดกันกลาง, Law of Excluded Middle)

ตัวอย่างสัจนิรันดร์อื่น ๆ ที่น่าสนใจ:
  • p → p (กฎเอกลักษณ์)
  • p ↔ p (กฎความเหมือน)

Example & Solution

โจทย์ตัวอย่าง: สัจนิรันดร์ (Tautology)

โจทย์ จงตรวจสอบว่าประพจน์ (p → q) ↔ (¬p ∨ q) เป็นสัจนิรันดร์หรือไม่
💡 วิธีคิดหาเหตุผลทีละขั้นตอน (Step-by-Step with Substitution):
  1. ขั้นที่ 1: วิเคราะห์ฝั่งซ้าย
    พิจารณา p → q จากกฎเงื่อนไข (Implication Law) สมมูลกับ ¬p ∨ q
  2. ขั้นที่ 2: สมมติกลุ่มตัวแปรย่อย (Substitution)
    เพื่อให้เห็นภาพชัดเจน กำหนดให้กล่องสัญลักษณ์ A ≡ ¬p ∨ q
    นั่นคือ ฝั่งซ้ายและฝั่งขวาของโจทย์มีหน้าตาเหมือนกันคือ A
  3. ขั้นที่ 3: แทนค่ากลับในโจทย์ดั้งเดิม
    จาก (p → q) ↔ (¬p ∨ q) จะถูกยุบลงเหลือเพียง A ↔ A
  4. ขั้นที่ 4: ตรวจสอบความจริงของตัวเชื่อม "ก็ต่อเมื่อ" (↔)
    ก็ต่อเมื่อจะเป็นจริง (T) เมื่อฝั่งซ้ายและฝั่งขวามีค่าความจริง เหมือนกัน ซึ่งเป็นไปได้ 2 กรณี:
    • กรณีที่ A เป็นจริง: T ↔ T ≡ T
    • กรณีที่ A เป็นเท็จ: F ↔ F ≡ T

สรุป: ผลลัพธ์เป็นจริง (T) ในทุกกรณีแน่นอน จึงเป็นสัจนิรันดร์ (Tautology)!

ตัวอย่างข้อขัดแย้งอื่น ๆ ที่น่าสนใจ:
  • ¬(p ∨ ¬p) (นิเสธของสัจนิรันดร์)
  • (p → q) ∧ (p ∧ ¬q)
    💡 ขยายความ: สังเกตว่าฝั่งขวา p ∧ ¬q คือ **นิเสธ** ของฝั่งซ้าย p → q โดยตรง (เพราะ ¬(p → q) ≡ p ∧ ¬q)
    เปรียบเหมือนประพจน์อยู่ในรูป X ∧ ¬X ซึ่งจะขัดแย้งกันเองและ **เป็นเท็จเสมอ (F)** ในทุกกรณี

Example & Solution

โจทย์ตัวอย่าง: ข้อขัดแย้ง (Contradiction)

โจทย์ จงตรวจสอบว่าประพจน์ (p ∧ q) ∧ ¬p เป็นข้อขัดแย้งหรือไม่
💡 วิธีคิดหาเหตุผล (Step-by-Step):
  1. ขั้นที่ 1: ใช้กฎการสลับที่และเปลี่ยนกลุ่ม (Commutative & Associative Law) เพื่อจัดกลุ่มใหม่:
    (p ∧ q) ∧ ¬p ≡ (p ∧ ¬p) ∧ q
  2. ขั้นที่ 2: พิจารณา p ∧ ¬p จากกฎของนิเสธ (Negation Law) ประพจน์ย่อยและนิเสธของมันเป็นจริงพร้อมกันไม่ได้
    ดังนั้น p ∧ ¬p ≡ F (เท็จเสมอ)
  3. ขั้นที่ 3: แทนค่ากลับลงไป จะได้ F ∧ q
  4. ขั้นที่ 4: โดยกฎการครอบงำ (Domination Law) ค่าเท็จเชื่อมกับอะไรก็ตามด้วย "และ" จะเป็นเท็จเสมอ
    ดังนั้น F ∧ q ≡ F

สรุป: เป็นข้อขัดแย้ง (Contradiction) เพราะมีค่าความจริงเป็นเท็จในทุกกรณี!

ระเบียบวิธีพิสูจน์ · Proof Method

การพิสูจน์โดยข้อขัดแย้ง (Proof by Contradiction)

แนวคิดหลัก เพื่อพิสูจน์ว่าประพจน์ p เป็นจริง ให้เรา สมมติว่านิเสธของมัน (¬p) เป็นจริง แล้วหาทางแสดงให้เห็นว่ามันนำไปสู่ ข้อขัดแย้ง (Contradiction) ซึ่งส่งผลให้ ¬p ต้องเป็นเท็จ และสรุปว่า p จริง
ตรรกะเบื้องหลัง
  • เราต้องการพิสูจน์ว่าเงื่อนไข ¬p → F เป็นจริง
  • ตามกฎเงื่อนไข: ¬p → F ≡ ¬(¬p) ∨ F ≡ p ∨ F ≡ p
  • ดังนั้น ถ้าเราแสดงได้ว่า ¬p นำไปสู่ เท็จ (F) แสดงว่าประพจน์ p ดั้งเดิมเป็นจริงอย่างแน่นอน!
ขั้นตอนการทำ
  1. ขั้นที่ 1: ตั้งสมมติฐานให้นิเสธเป็นจริง (สมมติว่า ¬p จริง)
  2. ขั้นที่ 2: หาเหตุผลเชิงตรรกะจนเกิดการชนกันของความจริง (เช่น ได้ทั้งจริงและเท็จพร้อมกัน)
  3. ขั้นที่ 3: สรุปว่าสมมติฐานแรกเริ่มเป็นเท็จ ดังนั้น p ต้องเป็นจริง

Proof Method

การพิสูจน์โดยข้อขัดแย้ง: ไม่มีจำนวนเต็มที่ใหญ่ที่สุด

วิธีการคิด สมมติให้สิ่งตรงข้ามเป็นจริง แล้วนำไปสู่ความขัดแย้งเชิงตรรกะ เพื่อสรุปว่าสิ่งที่เราสมมติเป็นไปไม่ได้
  1. สมมติให้ "มีจำนวนเต็มที่ใหญ่ที่สุด" สมมติชื่อว่า N
  2. สร้างจำนวนใหม่ขึ้นมา: M = N + 1
  3. เนื่องจาก N เป็นจำนวนเต็ม ดังนั้น M ก็ต้องเป็นจำนวนเต็ม
  4. เนื่องจาก 1 > 0 ส่งผลให้ M > N
  5. เกิดข้อขัดแย้ง! มีจำนวนเต็ม M ที่ใหญ่กว่า N ขัดแย้งกับข้อสมมติว่า N ใหญ่ที่สุด

ความสมมูลเชิงตรรกะ (Logical Equivalence)

นิยาม ประพจน์ P และ Q สมมูลกัน เขียนแทนด้วย P ≡ Q ก็ต่อเมื่อ มีค่าความจริงตรงกันทุกกรณีในตารางค่าความจริง (หรือ P ↔ Q เป็นสัจนิรันดร์)
วิธีการตรวจสอบความสมมูล:
1. สร้างตารางค่าความจริง
สร้างตารางแล้วเปรียบเทียบค่าความจริงทีละแถว เหมาะสำหรับตัวแปรน้อยตัว
2. ใช้กฎพีชคณิตของประพจน์
ใช้กฎการลดรูปและเอกลักษณ์เพื่อจัดรูปตรรกะ เหมาะสำหรับระบบที่มีความซับซ้อน

ชื่อกฎ รูปแบบสมมูล
เอกลักษณ์ (Identity)p ∧ T ≡ p ,    p ∨ F ≡ p
การครอบงำ (Domination)p ∨ T ≡ T ,    p ∧ F ≡ F
นิจพล (Idempotent)p ∨ p ≡ p ,    p ∧ p ≡ p
นิเสธสองชั้น (Double Negation)¬(¬p) ≡ p
การสลับที่ (Commutative)p ∨ q ≡ q ∨ p ,    p ∧ q ≡ q ∧ p
การเปลี่ยนกลุ่ม (Associative)(p ∨ q) ∨ r ≡ p ∨ (q ∨ r)

ชื่อกฎ รูปแบบสมมูล
การแจกแจง (Distributive)p ∨ (q ∧ r) ≡ (p ∨ q) ∧ (p ∨ r)

การดูดกลืน (Absorption)p ∨ (p ∧ q) ≡ p ,    p ∧ (p ∨ q) ≡ p
นิเสธ (Negation)p ∨ ¬p ≡ T ,    p ∧ ¬p ≡ F
เงื่อนไข (Implication)p → q ≡ ¬p ∨ q

Algebraic Proof

ตัวอย่าง: ลดรูปตรรกะด้วยกฎพีชคณิต

โจทย์ จงพิสูจน์ความสมมูล: ¬(p ∨ q) ∨ (¬p ∧ q) ≡ ¬p
¬(p ∨ q) ∨ (¬p ∧ q) ≡ (¬p ∧ ¬q) ∨ (¬p ∧ q) [กฎเดอมอร์แกน]
≡ ¬p ∧ (¬q ∨ q) [กฎการแจกแจงดึงตัวร่วม ¬p]
≡ ¬p ∧ T [กฎนิเสธ: ¬q ∨ q ≡ T]
≡ ¬p [กฎเอกลักษณ์: เชื่อม T ได้ตัวเดิม]

โจทย์ตัวอย่าง: พิสูจน์ด้วยกฎพีชคณิต

โจทย์ จงใช้กฎพีชคณิตเพื่อพิสูจน์ความสมมูล: ¬(p → q) ≡ p ∧ ¬q
💡 แสดงขั้นตอนการพิสูจน์ (Step-by-Step):
¬(p → q) ≡ ¬(¬p ∨ q) [กฎเงื่อนไข: p → q ≡ ¬p ∨ q]
≡ ¬(¬p) ∧ ¬q [กฎของเดอมอร์แกน: กระจายนิเสธและกลับตัวเชื่อม]
≡ p ∧ ¬q [กฎนิเสธสองชั้น: นิเสธซ้อนหักล้างกัน]

Classroom Activity 1

กิจกรรมที่ 1: จำแนกประเภทประพจน์

จงจำแนกว่าประพจน์เชิงประกอบต่อไปนี้เป็นประเภทใด (สัจนิรันดร์ / ข้อขัดแย้ง / ประพจน์กลาง)
  1. p ∨ ¬p
  2. p ∧ ¬p
  3. (p → q) ↔ (¬q → ¬p)
  4. p → q
✓ เฉลยและเหตุผล:
  • 1. สัจนิรันดร์: เพราะเชื่อมด้วย ∨ และค่าตรงข้ามกัน เป็นจริงเสมอ
  • 2. ข้อขัดแย้ง: เพราะเป็นจริงร่วมกันไม่ได้ เป็นเท็จเสมอ
  • 3. สัจนิรันดร์: ประพจน์เดิมสมมูลกับ แย้งสลับที่ เสมอ
  • 4. ประพจน์กลาง: ค่าความจริงขึ้นกับตัวแปรย่อย

Recap

สรุปเนื้อหาสัปดาห์ที่ 2

  • ประเภทประพจน์ย่อย: สัจนิรันดร์ (Tautology - จริงเสมอ), ข้อขัดแย้ง (Contradiction - เท็จเสมอ), ประพจน์กลาง (Contingency)
  • ตารางค่าความจริง: ใช้แสดงค่าความจริงของประพจน์ประกอบในทุกกรณี (2^n กรณี)
  • การพิสูจน์โดยข้อขัดแย้ง: สมมติสิ่งตรงกันข้ามแล้วหาข้อขัดแย้ง เพื่อสรุปผล
  • ความสมมูลเชิงตรรกะ (P ≡ Q): มีค่าความจริงตรงกันทุกกรณี ตรวจได้ด้วยตารางหรือกฎพีชคณิต
  • กฎพีชคณิตของประพจน์: เช่น กฎการแจกแจง กฎของเดอมอร์แกน และกฎเงื่อนไข (p → q ≡ ¬p ∨ q)
