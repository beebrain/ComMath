Concept 1.1

นิยามฟังก์ชัน (Function Definition $f: A \to B$)

DEF นิยามฟังก์ชัน
ความสัมพันธ์ $f$ จากเซต $A$ ไปยังเซต $B$ จะเป็น ฟังก์ชัน ก็ต่อเมื่อ: $$\mathbf{\forall x \in A, \exists! y \in B \text{ such that } (x, y) \in f}$$
2 RULES เงื่อนไขสำคัญ 2 ประการ
1. Total Mapping: สมาชิกตัวหน้า $x \in A$ ทุกตัว ต้องถูกนำมาจับคู่
2. Uniqueness: สมาชิกตัวหน้าแต่ละตัวจับคู่กับตัวหลังได้ เพียงตัวเดียวเท่านั้น
นิยามฟังก์ชัน4091606 · CH03-W08
Concept 1.2

ฟังก์ชันบริสุทธิ์ในคอมพิวเตอร์ (Pure Function)

CONCEPT ความหมายของฟังก์ชันในทางซอฟต์แวร์
ใน Functional Programming และคณิตศาสตร์ Pure Function คือฟังก์ชันที่:
  • Deterministic Output: ป้อนข้อมูลนำเข้าเดิม (Input) จะต้องให้ผลลัพธ์เดิมที่แน่นอนเพียงค่าเดียวเสมอ
  • No Side Effects: ไม่แอบไปแก้ไขสถานะตัวแปรภายนอกหรือหน่วยความจำอื่น
CONTRAST ฟังก์ชันที่ไม่บริสุทธิ์ (Impure)
เช่น ฟังก์ชัน random() หรือ ฟังก์ชันที่อ่านเวลาของระบบ now() ซึ่งให้ผลลัพธ์เปลี่ยนไปเรื่อยๆ แม้ไม่เปลี่ยน Input

Concept 1.3

การทดสอบเส้นแนวตั้ง (Vertical Line Test)

TEST กฎการทดสอบบนระนาบพิกัดฉาก
กราฟของความสัมพันธ์จะเป็นฟังก์ชัน ก็ต่อเมื่อ ไม่มีเส้นตรงแนวตั้งใดๆ ลากตัดกราฟเกินกว่า 1 จุด
EX ตัวอย่าง
• $y = x^2$ $\implies$ เส้นแนวตั้งตัด 1 จุดเสมอ $\to$ ✓ เป็นฟังก์ชัน
• $x^2 + y^2 = 1$ (วงกลม) $\implies$ เส้นแนวตั้งตัด 2 จุด $\to$ ✗ ไม่เป็นฟังก์ชัน

Concept 1.4

การตรวจสอบด้วยแผนภาพลูกศร (Arrow Diagram Test)

✓ เป็นฟังก์ชัน เกณฑ์ลูกศร
ทุกโหนดในเซตต้นทาง $A$ ต้องมีลูกศรพุ่งออก 1 เส้นพอดี
• ปลายทางจะชนกันได้ (Many-to-One ยอมรับได้)
• ปลายทางจะมีโหนดว่างเหลือได้
✗ ไม่เป็นฟังก์ชัน ข้อห้าม 2 ประการ
1. ห้ามมีโหนดต้นทางที่ไม่มีลูกศรออก (ไม่จับคู่สมาชิกครบ)
2. ห้ามมีโหนดต้นทางที่แตกกิ่งลูกศรออก $\ge 2$ เส้น (จับคู่หลายตัวพร้อมกัน)

Concept 1.5

โดเมน (Domain) และโคโดเมน (Codomain)

DOMAIN โดเมน $\operatorname{Dom}(f)$
เซตของสมาชิกต้นทางทั้งหมด:
$$\mathbf{\operatorname{Dom}(f) = A}$$ • สำหรับฟังก์ชัน โดเมนต้องเท่ากับเซตต้นทาง $A$ เต็มทั้งเซตเสมอ
CODOMAIN โคโดเมน (Codomain)
เซตปลายทางทั้งหมด $B$ ที่ระบุขอบเขตของผลลัพธ์ที่เป็นไปได้:
• ในการเขียนโปรแกรม เปรียบเสมือน Return Type (เช่น \texttt{int, float, string})
Domain & Codomain4091606 · CH03-W08
Concept 1.6

เรนจ์ (Range) หรือภาพของฟังก์ชัน (Image $f(A)$)

DEF เรนจ์ $\operatorname{Ran}(f)$
เซตของค่าผลลัพธ์จริงที่ถูกจับคู่โดยฟังก์ชัน $f$: $$\mathbf{\operatorname{Ran}(f) = \{f(x) \mid x \in A\} \subseteq B}$$
EXAMPLE ตัวอย่างการแยกแยะ
ให้ $f: \mathbb{R} \to \mathbb{R}$ โดย $f(x) = x^2$
• โดเมน: $\mathbb{R}$ (จำนวนจริงทั้งหมด)
• โคโดเมน: $\mathbb{R}$ (จำนวนจริงทั้งหมดที่ระบุไว้)
• เรนจ์: $[0, \infty)$ (เฉพาะจำนวนจริงที่ไม่เป็นลบเท่านั้น!) $\implies \mathbf{\operatorname{Ran}(f) \subsetneq \text{Codomain}}$

Concept 2.1

ฟังก์ชันหนึ่งต่อหนึ่ง (Injective / One-to-One)

DEF นิยามฟังก์ชันหนึ่งต่อหนึ่ง
สมาชิกปลายทางแต่ละตัวโดนจับคู่ ไม่เกิน 1 ครั้ง (ห้ามมีลูกศรชนกัน): $$\mathbf{\forall a, b \in A, f(a) = f(b) \implies a = b}$$ หรือเขียนในรูปประพจน์แย้งสลับที่ (Contrapositive): $$\mathbf{\forall a, b \in A, a \neq b \implies f(a) \neq f(b)}$$

Concept 2.2

การทดสอบเส้นแนวนอน (Horizontal Line Test)

TEST กฎเส้นแนวนอน
ฟังก์ชันจะเป็นหนึ่งต่อหนึ่ง ก็ต่อเมื่อ ไม่มีเส้นตรงแนวนอนใดๆ ลากตัดกราฟเกินกว่า 1 จุด
EX ตัวอย่าง
• $f(x) = 2x + 1$ $\implies$ เส้นแนวนอนตัด 1 จุดเสมอ $\to$ ✓ เป็น Injective
• $f(x) = x^2$ $\implies$ เส้นแนวนอน $y=4$ ตัด 2 จุด ($x=2, -2$) $\to$ ✗ ไม่เป็น Injective

Concept 2.3

ฟังก์ชันทั่วถึง (Surjective / Onto)

DEF นิยามฟังก์ชันทั่วถึง
สมาชิกในโคโดเมน $B$ ทุกตัวต้องถูกจับคู่อย่างน้อย 1 ครั้ง (ไม่มีตัวใดถูกทิ้งว่าง): $$\mathbf{\forall y \in B, \exists x \in A \text{ such that } f(x) = y}$$
CRITERIA เกณฑ์ตรวจสอบที่ง่ายที่สุด
ฟังก์ชัน $f: A \to B$ จะเป็นทั่วถึง ก็ต่อเมื่อ เรนจ์เท่ากับโคโดเมนพอดี: $$\mathbf{\operatorname{Ran}(f) = B}$$
ฟังก์ชันทั่วถึง4091606 · CH03-W08
Concept 2.4

ตัวอย่างเชิงตัวเลข: ฟังก์ชันทั่วถึง vs ไม่ทั่วถึง

✓ เป็นทั่วถึง
$f: \mathbb{R} \to \mathbb{R}$ โดย $f(x) = 3x - 5$

สำหรับ $y \in \mathbb{R}$ ใดๆ สามารถเลือก $x = \frac{y + 5}{3} \in \mathbb{R}$ ซึ่งทำให้ $f(x) = 3(\frac{y+5}{3}) - 5 = y$ เสมอ
✗ ไม่เป็นทั่วถึง
$f: \mathbb{Z} \to \mathbb{Z}$ โดย $f(x) = 2x$

เรนจ์มีเฉพาะจำนวนเต็มคู่ $\{\dots, -4, -2, 0, 2, 4, \dots\}$
จำนวนเต็มคี่เช่น $y = 3 \in \mathbb{Z}$ ไม่มี $x \in \mathbb{Z}$ ใดที่ $2x = 3$ ได้

Concept 2.5

ฟังก์ชันหนึ่งต่อหนึ่งทั่วถึง (Bijective Function)

DEF นิยาม Bijective (One-to-One Correspondence)
ฟังก์ชันที่เป็น ทั้งหนึ่งต่อหนึ่ง (Injective) และทั่วถึง (Surjective) พร้อมกัน: $$\mathbf{\text{Bijective} = \text{Injective} \land \text{Surjective}}$$
PROPERTY สมบัติการมีฟังก์ชันผกผัน
ความเป็น Bijective คือ เงื่อนไขจำเป็นและเพียงพอ (Necessary & Sufficient Condition) ที่ทำให้ฟังก์ชันมี ฟังก์ชันผกผัน ($f^{-1}$)

Concept 2.6

หลักการช่องนกพิราบ (Pigeonhole Principle)

THEOREM ทฤษฎีบทช่องนกพิราบ
ถ้านำนกพิราบ $k + 1$ ตัว ใส่ลงในรังนก $k$ รัง แล้วจะมีรังนกอย่างน้อย 1 รังที่บรรจุนกพิราบตั้งแต่ 2 ตัวขึ้นไป

ในมุมมองของฟังก์ชัน $f: A \to B$:
ถ้าเซตต้นทางมีสมาชิกมากกว่าเซตปลายทาง ($|A| > |B|$) แล้ว ฟังก์ชัน $f$ ไม่มีทางเป็นหนึ่งต่อหนึ่ง (Injective) ได้เลย! จะต้องมีค่าผลลัพธ์ชนกันเสมอ

Concept 2.7

การประยุกต์หลักการช่องนกพิราบในทางคอมพิวเตอร์

Concept 3.1

การประกอบฟังก์ชัน (Function Composition $f \circ g$)

DEF นิยามฟังก์ชันประกอบ
ให้ $g: A \to B$ และ $f: B \to C$ ฟังก์ชันประกอบ $f \circ g: A \to C$ คือ: $$\mathbf{(f \circ g)(x) = f(g(x))}$$ • นำค่า $x$ ป้อนให้ฟังก์ชัน $g$ ทำงานก่อน
• เมื่อได้ผลลัพธ์ $g(x)$ ให้นำค่านั้นไปป้อนต่อเป็น Input ของฟังก์ชัน $f$
การประกอบฟังก์ชัน4091606 · CH03-W08
Concept 3.2

ตัวอย่างการคำนวณฟังก์ชันประกอบทีละขั้นตอน

EXAMPLE ให้ $f(x) = 2x + 3$ และ $g(x) = x^2 - 1$
1. หา $(f \circ g)(x)$ :
$$(f \circ g)(x) = f(g(x)) = f(x^2 - 1) = 2(x^2 - 1) + 3 = \mathbf{2x^2 + 1}$$ 2. หา $(g \circ f)(x)$ :
$$(g \circ f)(x) = g(f(x)) = g(2x + 3) = (2x + 3)^2 - 1 = \mathbf{4x^2 + 12x + 8}$$
CAUTION ข้อควรระวัง
$(f \circ g)(x) \neq (g \circ f)(x)$ — การประกอบฟังก์ชัน ไม่มีสมบัติการสลับที่ (Non-commutative)

Concept 3.3

ฟังก์ชันผกผัน (Inverse Function $f^{-1}$)

DEF นิยามฟังก์ชันผกผัน
ถ้า $f: A \to B$ เป็นฟังก์ชันหนึ่งต่อหนึ่งทั่วถึง (Bijective) จะมีฟังก์ชันผกผัน $f^{-1}: B \to A$: $$\mathbf{f^{-1}(y) = x \iff f(x) = y}$$ $$\mathbf{(f^{-1} \circ f)(x) = x \quad \text{และ} \quad (f \circ f^{-1})(y) = y}$$
ฟังก์ชันผกผัน4091606 · CH03-W08
Concept 3.4

3 ขั้นตอนการหาฟังก์ชันผกผัน $f^{-1}(x)$

STEP 1
ตั้งสมการ $y = f(x)$
เขียนฟังก์ชันในรูปของตัวแปร $y$ เช่น $y = 3x - 5$
STEP 2
แก้สมการหา $x$
จัดรูปสมการให้ตัวแปร $x$ อยู่เดี่ยวๆ: $3x = y + 5 \implies x = \frac{y + 5}{3}$
STEP 3
สลับตัวแปรกลับ
แทน $x$ ด้วย $f^{-1}(x)$ และแทน $y$ ด้วย $x$: $\mathbf{f^{-1}(x) = \frac{x + 5}{3}}$

Concept 4.1

ฟังก์ชันพื้น (Floor Function $\lfloor x \rfloor$)

DEF นิยามฟังก์ชันพื้น
จำนวนเต็มที่มากที่สุดที่ น้อยกว่าหรือเท่ากับ $x$ (การปัดเศษลง): $$\mathbf{\lfloor x \rfloor = \max \{n \in \mathbb{Z} \mid n \le x\}}$$
EXAMPLES ตัวอย่างเชิงตัวเลข
• $\lfloor 3.8 \rfloor = 3$
• $\lfloor 3.0 \rfloor = 3$
• $\lfloor -3.2 \rfloor = \mathbf{-4}$ (ข้อควรระวัง: จำนวนลบปัดลงไปหาค่าที่น้อยกว่า)

Concept 4.2

ฟังก์ชันเพดาน (Ceiling Function $\lceil x \rceil$)

DEF นิยามฟังก์ชันเพดาน
จำนวนเต็มที่น้อยที่สุดที่ มากกว่าหรือเท่ากับ $x$ (การปัดเศษขึ้น): $$\mathbf{\lceil x \rceil = \min \{n \in \mathbb{Z} \mid n \ge x\}}$$
EXAMPLES ตัวอย่างเชิงตัวเลข
• $\lceil 3.2 \rceil = 4$
• $\lceil 3.0 \rceil = 3$
• $\lceil -3.8 \rceil = \mathbf{-3}$ (ข้อควรระวัง: จำนวนลบปัดขึ้นไปหาค่าที่มากกว่า)

Concept 4.3

การประยุกต์: การแบ่งหน้าข้อมูล (Pagination)

FORMULA สูตรคำนวณจำนวนหน้าเว็บ
เมื่อมีข้อมูลทั้งหมด $N$ รายการ และต้องการแสดงผลหน้าละ $S$ รายการ: $$\mathbf{\text{จำนวนหน้าทั้งหมด} = \lceil N / S \rceil}$$
EX ตัวอย่าง
ระบบฐานข้อมูลมีบทความ $N = 127$ รายการ กำหนดแสดงหน้าละ $S = 10$ รายการ:
$$\text{จำนวนหน้า} = \lceil 127 / 10 \rceil = \lceil 12.7 \rceil = \mathbf{13 \text{ หน้า}}$$ หน้าสุดท้าย (หน้าที่ 13) จะมีข้อมูลเหลือแสดง 7 รายการ

Concept 4.4

ฟังก์ชันมอดุโล (Modulo Operation $a \bmod m$)

DEF นิยามฟังก์ชันมอดุโล
เศษที่เหลือจากการหารจำนวนเต็ม $a$ ด้วยจำนวนเต็มบวก $m$: $$\mathbf{a \bmod m = r \quad (0 \le r < m \text{ โดย } a = qm + r)}$$
EXAMPLES ตัวอย่างคำนวณ
• $17 \bmod 5 = 2 \quad (17 = 3 \times 5 + 2)$
• $-8 \bmod 3 = 1 \quad (-8 = -3 \times 3 + 1)$

Concept 4.5

การประยุกต์มอดุโล: คิววงกลม (Circular Queue / Round-Robin)

FORMULA การวนกลับมาตำแหน่งเริ่มต้น
การเลื่อนตำแหน่งดัชนีใน Circular Buffer หรือ Round-Robin Scheduling บนอาร์เรย์ขนาด $N$: $$\mathbf{\text{next\_index} = (\text{current\_index} + 1) \bmod N}$$
EX ตัวอย่าง
อาร์เรย์ขนาด $N = 5$ (ดัชนี $0, 1, 2, 3, 4$):
เมื่ออยู่ที่ดัชนี $4 \implies (4 + 1) \bmod 5 = 5 \bmod 5 = \mathbf{0}$ (วนกลับมาหัวแถวอัตโนมัติ)

Concept 4.6

ฟังก์ชันแฮช (Hash Function $h(k) = k \bmod m$)

DEF นิยามฟังก์ชันแฮช
ฟังก์ชันที่แปลงคีย์ข้อมูลขนาดใหญ่ $k$ ให้เป็นดัชนีช่องตารางขนาดจำกัด $m$: $$\mathbf{h(k) = k \bmod m}$$
EX ตัวอย่าง
กำหนดตารางขนาด $m = 7$ (ช่อง $0$ ถึง $6$):
• $h(24) = 24 \bmod 7 = \mathbf{3}$
• $h(15) = 15 \bmod 7 = \mathbf{1}$

Concept 4.7

การชนกันของแฮช (Hash Collision)

PROBLEM นิยามการชนกัน
เกิดขึ้นเมื่อคีย์ข้อมูลที่ต่างกัน ($k_1 \neq k_2$) ถูกแปลงแล้วได้ดัชนีช่องเดียวกัน: $$\mathbf{h(k_1) = h(k_2)}$$
EX ตัวอย่าง
สำหรับ $h(k) = k \bmod 7$:
• $h(15) = 15 \bmod 7 = 1$
• $h(50) = 50 \bmod 7 = 1$
เกิดการชนกันที่ช่องดัชนี 1! ต้องใช้ Separate Chaining หรือ Linear Probing ในการแก้ไข

Concept 4.9

การทำงานบนหน่วยความจำ (Call Stack Trace)

STACK TRACE การคำนวณ $3!$ ($f(3)$)
$f(3) \to 3 \cdot f(2)$
$\quad \to 2 \cdot f(1)$
$\quad\quad \to 1 \cdot f(0) \implies \text{Base Hit: คืนค่า } 1$
$\quad \leftarrow 2 \cdot 1 = 2$
$\leftarrow 3 \cdot 2 = \mathbf{6}$
OVERFLOW ข้อควรระวัง
หากไม่มี Base Case หรือเงื่อนไขหยุดไม่ถูกต้อง ฟังก์ชันจะกินพื้นที่ Stack บน Memory จนเต็มและเกิดข้อผิดพลาด Stack Overflow!
